# 测量工作台

本次调整按“易用、效率优先，其次美观与专业表达”的顺序实施。原有图片标签、图片列表、测量工具菜单、数字类别快捷键和导出流程继续可用，不增加测量前的向导或逐次确认。

## 第一批：高频操作

- 图片与测量状态栏始终显示当前图片序号、名称、新测量类别和标定状态。可用上一张、下一张、图片下拉列表或 `Ctrl+PgUp/PgDown` 切换图片。
- 窄窗口中该状态栏自动分为两行，保留图片切换、类别、面积工具和标定提示。正常工作宽度保持单行；极窄窗口可配合“专注画布”收起侧栏。
- 未标定图片显示醒目的“未标定 · 结果为 px / px²”。点击提示可开始标定、应用现有预设或查看标定详情。预设沿用原来的应用范围选择。
- 测直径时，`B` 在手动线段和边缘吸附之间切换；切图保留当前工具。边缘吸附与状态栏的对象捕捉仍是两个独立功能。
- “新测量归类”只影响随后创建的测量。右侧“当前对象”的类别框修改已选中的测量，支持原有撤回流程。
- “导出模板”和“叠加图”直接进入原有导出窗口。模板优先使用上次选择的路径，没有历史选择时使用首个已配置模板；未配置模板时仍可在原有导出窗口处理。导出范围、单位校验、模板预检和保存位置沿用原流程。
- 无图片时显示打开图片、打开项目和开始采集入口，可直接一次打开多张图片。
- 数字切片的开始、停止、准备状态和进度固定在预览下方；隐藏侧栏后仍能看到。硬件控制和采集生命周期不变。

## 第二批：布局与连续测量

- 测量分析、实时采集、数字切片采用稳定的顶部入口，直接复用已有操作。
- 左侧“图片与类别”同时显示图片列表和类别列表，“ROI / 辅助”单独成页。小屏保留原有单侧布局与面板切换习惯。
- 面积工具的多边形、自由圈选、魔棒、同类扩选有直接按钮，原有工具菜单继续可用。
- 同一对象在多边形与自由圈选之间切换时保持添加/剔除状态，`T` 仍可切换。换选对象或跨出手动面积工具后沿用原来的状态初始化。
- 魔棒剔除保留 `1/2/3` 选择剔除形状；增加 `Alt+1–9` 切换类别。剔除形状按钮主体循环切换形状，右侧箭头直接选择。
- 右侧首先显示当前对象的数值、单位、类别、来源图片及状态，完整属性由“属性”展开。统计、记录、标定和面积识别仍可展开使用。
- 展开底部完整结果时，右侧重复的记录区域暂时隐藏；两个记录视图继续共享过滤条件和选择。关闭底部结果后恢复右侧记录。
- “专注画布”临时收起侧栏；“图像与结果复核”收起侧栏并显示完整结果。再次关闭预设、手动打开面板、进入采集或关闭最后一张图片时恢复正常布局。窗口关闭前恢复原布局再保存偏好。
- 新用户的右侧默认宽度改为 320，标定详情默认折叠。已有显式保存的宽度与展开状态继续生效，恢复默认布局后才采用新默认值。

## 第三批：视觉与专业细节

- 亮暗主题的常规图标随文字色调整；浅色主题的选中背景与文字对比度加强。工作区、面板开关、测量工具和折叠标题采用不同的状态表达。
- 减少重复卡片边框和工具栏留白。顶部常用操作保留文字，窗口不足以容纳全部命令名称时，其余工具栏按钮以图标显示，菜单和提示保留完整名称。
- 画布“标签”可选全部、仅选中、隐藏，只影响屏幕上的长度和面积标签；数值、几何、计数编号与导出样式不受影响。默认仍显示用户原来启用的标签，切回“全部”恢复原样。
- `Ctrl+K` 查找功能支持名称、菜单路径及常用别名，如“直径”“原始记录”。执行仍调用原有命令；当前不可用的命令不执行。

## 验证范围

交互回归覆盖 12 张图片切换、标定提示、吸附切换、类别与当前对象的区分、面积剔除状态、魔棒形状与类别快捷键、输入框焦点、模板/叠加图入口、布局恢复和采集按钮可达性。

渲染回归覆盖直接绘制与瓦片缓存、纯面积及混合几何、不同屏幕像素比、选中切换和标签恢复。另行实际写出 PNG，比较各屏幕标签模式的导出文件与测量数据。

截图使用隔离设置与合成演示数据，不读写用户项目，也不触发真实采集。Windows 多显示器缩放、真实电镜/光学批量操作及相机和样品台联调仍需在目标机器验收；截图与本地回归不代替这部分验收。

### 三批改造验证结果（2026-09-06）

- macOS、Python 3.13、PySide6 / Shiboken6 6.10.2，采用 Qt offscreen 平台。
- 全部 138 个测试文件分为 152 个独立进程运行；较大的画布与导出文件按 20 个用例分组。共 **2435 项测试、1416 项子测试通过**，无失败组。新增高频工作流测试单独运行 **15 项通过**。
- 完成亮暗主题、12 张演示图片、未标定、小屏、结果复核与采集操作区截图核对；极窄的专注画布场景验证了 692 像素窗口中的快捷栏可达性。
- 新增测试共用一个应用实例，配置文件重定向到临时目录；窗口布局的延迟刷新绑定窗口生命周期，销毁窗口后不继续访问控件。
- `git diff --check` 通过；三批改造已提交为本地版本 `9d5a9a4`，未发布。

**尚未消除的限制：** 单进程运行全量测试时仍偶发 Qt 原生段错误，曾发生于创建 QAction 和结果面板对象时。失败位置不固定，根因尚未确认；不能据分组测试通过而宣称这个问题已解决。另一次单进程运行到结束时有 2433 项通过、1 项窄窗口断言失败，该布局问题已修复并单独复验。当前状态是三批功能已实现、分组回归通过，**稳定性与目标机器发布验收尚未完成**。

本地证据保存于 `build/ui-modernization-review/`：`final-isolated-regressions/results.json` 为全部分组结果，`final-full-tests.log` 为最后一次单进程原生崩溃记录，`final-area-light.png`、`final-uncalibrated-small.png`、`final-review-dark.png`、`final-empty.png` 为演示截图。该目录属于构建输出，不纳入源代码提交。

## 截图反馈的八项修正（2026-09-06）

设计重点是保持连续操作的位置稳定，并让常用控件在最小尺寸下仍有完整的点击区域。

| 反馈 | 调整与原因 |
| --- | --- |
| 项目栏最窄时裁切 | 保持 220 逻辑像素的宽度下限。滚动内容跟随视口宽度，类别卡片在视口变化后重新布局，数量徽标不再留在旧宽度之外。缩短表头为“本图 / 全部”，按钮按可用宽度换行，长类别名省略并提供完整提示。 |
| 测量记录数量不协调 | 数量只在标题右侧显示一次，采用小型徽标；筛选后显示“当前可见 / 总数”。底部拖动手柄改为短小的中性色线，减少与进度条的混淆。 |
| 图片切换、归类区域缺乏层次 | 图片导航和新测量归类各自形成有边界的控件组，名称紧贴类别框；面积工具和剔除入口仍直接可点。窄窗口保留自动换行。 |
| 对象捕捉文字贴近箭头 | 为箭头预留独立的 20 像素区域及文字间距。按钮主体仍直接开关捕捉，箭头仍展开捕捉类型。 |
| 属性按钮不能收起 | “属性”成为开关，并与详细属性区域的展开状态同步。再次点击收起；通过区域标题收起时，按钮也解除选中。 |
| 当前对象变化挤压记录 | 摘要分为三个固定高度的区域：当前对象类别与属性按钮、数值与单位、两行来源信息。空选、单选、多选高度一致；长文件名省略并保留完整提示。比单独放置类别行更节省小屏空间。 |
| 计数与辅助点图标相同 | 计数改用数字计数器图标，辅助点使用独立的点图标；缺少图标字体时也分别使用计数刻痕和点的绘制方案。画布中的计数标记不变。 |
| 关闭项目后工具文字消失，以及系统主题异常 | 恢复旧窗口状态时，为测量工具和图片状态栏补回独立行，避免图片名挤占测量工具宽度。三种主题共用 Fusion 控件样式与图标尺寸；“跟随系统”只跟随系统明暗，并响应运行期间的切换。 |

系统主题更新延后到 Qt 完成平台调色板切换后执行，避免主题信号发出时仍使用旧调色板；实现依据见 [Qt QStyleHints 文档](https://doc.qt.io/qt-6/qstylehints.html#colorScheme-prop)。用户的主题选项继续保存为“跟随系统”，不会改为固定的浅色或深色。

字体仅初始化一次，避免重复设置全局字体清掉 macOS 的控件专用字体、把现有按钮文字放大。主题样式更新完成后重新计算主命令栏的可用宽度，保持末尾“查找”等入口可达。另行设置工具栏内部布局的边距，避免 Qt 在样式刷新后额外加入上下各 6 像素，把小屏窗口撑出可用区域。

### 修正验证

- 最后一轮全套运行有 1 项小屏高度断言失败，其余组通过；定位并修正工具栏内部边距后，工作流 27 项与专业工作台 33 项分别再次通过，后者另含 18 项子测试。原始全量日志与修正后日志分别保留，汇总记录不会覆盖失败证据。
