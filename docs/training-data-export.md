# 训练数据导出说明

入口位于“文件 → 导出 → 训练数据…”。导出只使用已确认的面积对象；测量线、计数点和辅助几何会在检查报告中列出并跳过。

支持的输出为：

- COCO 实例分割：未压缩 RLE，可保留孔洞、多连通区域和实例重叠；`coco/annotations/` 同时生成按训练/验证分组的标注文件。
- YOLO 检测：每个面积实例转换为边界框。
- YOLO 分割：只无损支持单一外轮廓；复杂拓扑默认跳过，也可由用户明确选择只保留最大外轮廓。
- 语义分割标签图：背景值为 `0`，缺失图块与实例重叠值为 `65535`。
- 实例分割标签图：使用 32 位 TIFF，并用同名 JSON 保存实例、类别和原对象映射；忽略值为 `4294967295`。

普通图片按权威源像素导出。数字切片只重建标注时冻结的局部视野与焦层，不分配完整切片图像；缺失图块不会作为普通背景参与标签。旧对象若没有焦层与局部范围记录，只能在用户确认风险后按当前焦层/视野导出，并会在 `export_report.json` 中标为来源未核实。

训练/验证划分以独立源图或原始数字切片为组，相同切片的焦层和局部样本不会跨集合。只有一个独立来源时保持在 `all` 目录，不制造会造成数据泄漏的随机切分。
