# 采集页面加载与 Excel 操作

版本保持 0.4.14。本次改动使用现有模板选择与数据同步规则。

## 进入采集与试验

切换被接受后先显示页面框架。首次打开含量或直径试验时，页面分阶段准备；超过 150 ms 才出现进度动画。已打开过的试验页直接复用。相机连接和 Excel 关联分别显示自己的状态，不阻止查阅记录或配置试验。

相机探测、OpenCV 设备打开和首帧等待移出界面线程。同一设备任务串行执行；取消表示撤销本次使用意图，仍在驱动中执行的操作完成并释放后，才允许后续连接。返回已知设备优先使用当前设备清单，连接失败再刷新。设备菜单提供主动刷新。

准备过程中可以返回测量分析或选择其他页面。旧页面、旧项目及旧设备请求的迟到结果不会重新切换界面。页面准备失败时，占位区提供重试和返回入口。

## Excel 主按钮

底部表格图标与主色按钮是本试验的 Excel 入口，下拉箭头保留同步、报表及详情操作。

| 主按钮 | 含义 |
| --- | --- |
| 查看 Excel | 显示现有绑定的工作簿，不重新写入测量数据 |
| 打开 Excel | 尚未关联或工作簿已关闭；重建工作簿并补齐已确认输入后显示 |
| 连接中… | 正在建立关联；重复点击合并为同一操作，下拉菜单仍可用 |
| 恢复同步 | 用户主动停止后，明确点击才恢复 |
| 查看异常 | 模板或映射需要处理；查看原因、模板设置或重试 |

关闭 Excel 不会触发自动重开。点击主按钮或下拉菜单中的“重新输出测量数据”，才会恢复并显示。重建只能恢复 FDM 已确认的数据；Excel 中没有保存的手工内容无法恢复。

“重新输出测量数据”在对应输入批次确认后显示一次工作簿。普通后台更新不反复抢焦点。切换试验、离开采集页或停止同步会撤销尚未执行的显示意图。

Excel 正在编辑、保存或执行宏时，点击查看会先展示对应窗口，数据与工作簿激活等待 Excel 可以接受操作后继续。最小化窗口会恢复；若 Windows 不允许前置，界面提示通过任务栏打开，这不代表测量数据写入失败。

## 状态颜色

- 红色表示测量输出、模板更换或报表操作失败，具体失败类型放在文字开头。
- 黄色表示工作簿关闭、Excel 忙碌或需要处理的提示。
- 正常同步与主动停止使用正常文字色；“尚未另存”等文件保存状态单独保留，不当作同步错误。

模板更换失败但旧工作簿仍存在时，可以继续查看旧工作簿；界面明确说明尚未完成更换，不偷偷改用其他模板。

## 验证与诊断

`AcquisitionWorkbench.transition_timings()` 记录框架绘制、分阶段页面准备、设备连接、首帧及 Excel 就绪；`CaptureSessionManager.device_operation_timings()` 提供串行设备任务耗时。它们用于区分界面等待与设备实际启动耗时。

源码验证入口：

```text
python scripts/validation/validate_acquisition_transition.py --output <新的本地证据目录> --theme dark --scale 1
python scripts/validation/verify_excel_presentation.py --content-template <含量模板副本> --diameter-template <直径模板副本> --output <新的本地证据目录>
```

前者使用慢设备模拟和模拟 Excel，后者要求 Windows 桌面 Excel 并只操作新建的独立测试实例。两者使用独立配置目录，不代表真实相机的驱动兼容性或吞吐验收。截图、录像和运行生成物保存在本地，不加入 Git。
