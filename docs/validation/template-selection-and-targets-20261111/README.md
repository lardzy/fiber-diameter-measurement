# 报告模板切换与试验数量提醒验证

版本仍为 **0.4.14**；本轮按用户请求仅提交到本地，不推送、不制作安装包。截图、Excel 副本和完整运行日志保存在 `build/template-selection-20261111`，不进入 Git。

## 修复的调用链

报告页原先只保存模板选择并读取标准，没有通知正在运行的实时 Excel 协调器；重入同一试验又因修订未变化继续复用旧簿。默认模板另外采用首次复制的个人工作副本，所以仅替换安装目录 `sheet.xlt` 也不会覆盖个人副本。

现在“选择模板”明确调用 `LiveExcelManager.replace_template`，即使路径相同也建立新代次，先验证输入，再解除旧关联，从所选文件建立新工作簿并完整输出当前试验。旧簿不保存、不关闭，保留人工备注。其他试验固定其原有模板、输入映射和方法标签；普通同步及“重新输出测量数据”不会切换模板。新的试验采用最新选择。

在途或部分写入批次先按原身份完成；尚未派发的连续选择合并为最新项。停止、退出取消未派发的更换。失败显示所选路径与原因，不改用其他默认模板。模板方法列表绑定文件及映射身份，迟到的旧列表被丢弃；明确修改方法映射也建立新关联。

模板路径分为“后续试验模板”和“当前实时工作簿模板”。路径状态使用缓存，不在每次状态显示时解码全部测量数据。保留个人工作副本的首次复制契约，避免覆盖用户的公式和宏；明确选择的路径始终优先。

## 新增数量偏好

- 主设置 → 采集与试验 → 测量与图片存档 → 数量提醒：共享含量总目标，默认 1500，按每位操作者、经纬方向分别累计实测＋补计，应用到所有已有及以后新建的含量试验。
- 纤维类别库及本次参数：分别设置实测直径和补计／计数目标，均为正整数。实测留空继承试验默认；补计留空不提醒，统计不含实测。本试验单类实测覆盖仍优先。
- 类别库默认在选用时形成试验副本；新字段完整进入类别库和项目的保存／读取。明确设置的类别目标也适用于旧含量试验。直径试验继续采用当前操作者整体实测目标。
- 总目标只保存于 `trial-defaults.json`，运行时覆盖旧项目总目标，不改测量值、项目序列化、撤销或 Excel 投影。达到提醒但可继续，批量跨越、撤销、重开及修改阈值不会重复补弹。
