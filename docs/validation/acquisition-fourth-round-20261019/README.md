# 第四轮候选点选与测量证据交付

产品版本维持 **0.4.10**。本轮在现有 PySide6、测径算法、标定及项目记录语义上扩展交互；安装候选用构建 ID 和 SHA-256 区分。实现随第五轮变更一并纳入版本控制，安装器仍按构建时的源码快照追溯。

## 已实现

- 测量编号使用稳定的 `#序号`，候选使用 `C序号`。编号按可见视口避让线段、端点和其他编号；拥挤时隐藏次要文字，保留悬停查看。缩放和滚动不改变测量坐标。
- 图像固定控制区提供全图分析／刷新、自动开关、候选显示和 20%～100% 不透明度。候选与审核表双向突出显示；隐藏候选同时关闭命中。
- 新增候选点选方式。点击使用当时的当前类别；手工方式继续原先选／后选流程。部分接受不清空余项，编号稳定；接受核验队列上限 16，Esc 取消未入账项。越限、疑似重复进入审核，不猜测入账。
- 自动分析默认关闭并跨工作区、重启记忆。额外稳定 300 ms 后每周期一次，空结果和全部接受不会循环重跑。来源、批次及精确帧 ID 校验阻止旧结果重新显示。
- 独立固定源帧对齐保持原始阈值：平移 ≤1 像素，响应 ≥0.6，NCC ≥0.95，梯度能量比 0.5～2；低纹理和无效数值拒绝。正常情况下图像与核验结果同步呈现；核验落后时进入有界即时预览回退，隐藏并禁止点击未核验候选。恢复需至少 2 秒并连续 8 次及时核验，不反复逐帧等待。
- 新试验默认局部 JPEG95／4:4:4，原分辨率、64 像素边距、至少 256×256（受原图边界限制），透明输入用局部 PNG。手工原落点和自动统计实际使用的采样几何均纳入裁剪。旧试验维持原存档语义。
- 证据按独立 ID 回填，支持同帧多裁剪、PNG/JPEG 保存、重开和另存。原图片不烘焙标注；复核只减去裁剪原点绘制，数值修订明确区分原测值。
- 点击最新测值或“证据”按钮打开复核，可固定为应用所属小窗、跟随最新或锁定历史；移动视场后仍能复核上一条。两类试验共享窗口偏好，关闭未使用页面不覆盖最新选择。
- 统一主窗口与试验撤销／重做路由，防止停止采集后快捷键修改隐藏图片；文本输入仍使用原生撤销。审核表的已接受行跟随正式记录改类和撤销重做。
- “全图分析”旁菜单导出离线性能 JSON，包含有界采样、指标定义、采集窗口、帧率和帧龄。没有采到的阶段输出 null；启动与传输无法独立拆分的部分明确记为合计开销。

显示、透明度、自动开关、视窗布局不修改试验；存档策略属于需要保存的试验配置。自动候选和失败结果不入账、不生成证据。候选测值和图片始终来自该批分析帧。

## 验证入口与边界

- [本机全量回归](macos/summary.json)：5365 项通过、13 项跳过、1653 个子测试通过；后续计时修复通过 11 项专项，最终控制器通过 210 项、标注布局通过 143 项定向回归。全量与后续定向范围及源码指纹分别记录，测试数量不重复相加。
- [视觉与导航](visual/README.md)：四主题 × 四种尺寸／缩放，共 16 场景；实际导航 290 次；截图、两段 Qt 采样录像、几何及图像像素检查、来源指纹和哈希。
- [性能数据与定义](candidate-performance/README.md)：实际自动分析 worker 延迟、持续 JPEG 写入及候选对齐对照；macOS 合成测试与截图输入不冒充真实相机。
- [Windows 候选流程](WINDOWS_CANDIDATE_WORKFLOW.md)：隔离源码、内部包、限定 FDM 注册项备份／恢复、普通启动、Excel 与旧安装保护证据；实际结果以 `windows/` 中日志和报告为准。
- [离线 Microview 测试步骤](OFFLINE_MICROVIEW_ACCEPTANCE.md)：真实设备、30 分钟动态采集、多显示器和对齐阈值仍待使用候选包验证。

1600×900 客户区：100% 完整显示 9 类，125% 为 4 类；150% 仅 1 类完整可见，使用局部滚动。1366×768 为 5 类。缩放测试不替代 Windows 物理 DPI 和跨屏测试。录像为 Qt 控件采样，不是系统桌面录屏，因此不能证明 SDK 原生窗口行为。

真实性边界：项目没有连接 Microview 实体相机。独立对齐阈值是保守初值，必须在真实光学纹理、模糊、曝光变化和慢漂移下复核；不称为识别准确率。JPEG 是有损目视证据，不用于重新计算原始测值。自动多截面测量的裁剪可能接近全图，不能承诺每条固定 256×256 或固定压缩率。

## 最终生产代码的补充验证

Windows 原生 Qt 模拟压力使用 768×576 持续输入、每 150 ms 一次实测和局部 JPEG 存档，持续 30 秒：基线 30.3015 FPS／P95 帧龄 9.155 ms；开启候选核验后 30.3166 FPS／18.936 ms。198/198 张证据写入成功，FPS 未下降，帧龄增加 9.781 ms，小于一个约 33 ms 帧周期。原始数据及此前失败组均保留在 `windows/performance-*.json`。

这项压力测试使用固定候选和手工测量，不代表全图算法或真实 Microview 的连续点选能力。高负载发生 3 次即时预览回退，2354 次绘制中 695 次包含可见候选（29.52%，不是可点击墙钟时长）。未核验候选暂时隐藏、不可点击；不能声称候选始终可点。实际全图子进程、真实导航点选和证据复核已在另一组功能测试中单独覆盖。

Windows 源码版另通过四主题 × 四种尺寸／缩放的 16 场景，290 次真实导航，实际物理截图尺寸经过断言；其 12 项视觉相关生产文件指纹与 macOS 最终矩阵一致。最后候选控制器、布局及慢核验定向回归为 154 项通过。它们仍不能代替离线实体相机和多显示器验收。

安装包路径、构建 ID、SHA-256、安装后验证与环境恢复结果见 [最终交付报告](DELIVERY.md)。
