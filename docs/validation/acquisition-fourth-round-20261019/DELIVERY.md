## 明确保留的边界

- 安装版 GUI 使用无相机的已有记录夹具，验证复核、导航、停靠与报告；安装版中真实自动分析子进程的完整采集点选链尚未验证，该链已在 Windows 源码版真实导航矩阵覆盖。
- **真实 Microview 尚未测试**。离线相机原帧、30 分钟动态采集、对齐阈值、4K／跨显示器移动仍待验收。Windows 为 ARM64 Parallels 上的 AMD64 应用，与实体 x64 设备分开记录。
- 高负载时为维持预览流畅，会暂时隐藏未核验候选并禁止点击，核验阈值不降低。压力组 2354 次绘制中 695 次候选可见，约 29.52%；这不是墙钟可点击比例或识别准确率，不表示候选始终可点。持续候选可用性需要真机复测。
- 1600×900 的 100%／125% 分别完整显示 9／4 类；150% 只有 1 类完整可见，需要局部滚动。1366×768 为 5 类。
- 视频是 8 fps Qt 控件采样及复核窗合成，不是完整桌面录屏，不能证明 SDK 原生窗口没有瞬时闪烁。
- JPEG 是有损目视证据，不重新计算测值；自动多截面采样的局部范围可能接近整图。旧试验不自动迁移。
