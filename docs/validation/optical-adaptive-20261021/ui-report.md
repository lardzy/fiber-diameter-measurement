# 普通光学适配：界面回归记录

日期：2026-10-21。应用版本保持 **0.4.10**。此报告限于 macOS 本地 Qt offscreen、隔离配置和模拟帧，不代表 Windows 安装版或 Microview 真机验收。

## 已实施的界面接入

- 算法菜单与高级页使用统一注册表：传统全图（CU 兼容）、玻纤多尺度（CU 兼容）、普通光学适配；默认仍为传统。
- 应用偏好升到 v4，保留已有 v2/v3 的算法、交互及手工算法；手工两点/拖线手势仍由既有试验工作区配置管理，迁移不改动。
- 全图分析菜单及高级页提供独立的普通光学设置窗口，没有增加主操作台常驻行。成像结构、可选空白参考、查看参考、光照检查均在此窗口内。
- 保存设置只作用于下一次分析；“应用并刷新候选”是独立显式动作。当前候选、手工草稿、试验账本和项目修改状态不因设置保存改变。
- 候选及历史记录提供中文结构、边缘信噪比、宽度变化等说明；这些指标不是准确率，不新增测量确认门槛。疑似重复仍沿用既有核对流程。
- 光照页首先展示中文亮度、近饱和/近黑像素占比、背景不均、图像对比、清晰度指标及最多两条建议；详细 JSON 可复制。平场未应用会在入口提示和窗口中明确说明。
- 空白采集收集 5 张不同源帧，使用共享帧租约及准备/保存工作区预算；来源或配置变化取消，窗口关闭释放采集中租约。后台单在途，光照工具最多 2 Hz。
- 离线 ZIP 包含配置、光照/分析诊断以及经哈希和解码校验的参考文件。参考不存在、损坏或预算不足时仍导出诊断，记录 `flat_reference_error` 并略过无效图片。参考解码有独立预算。

## 自动化结果

执行：

```text
.venv/bin/python -m pytest -q \
  tests/test_optical_settings_ui.py \
  tests/test_trial_assistance_ui.py \
  tests/test_live_experiment_content_workspace.py \
  tests/test_trial_records.py
```

结果：**137 passed in 5.13s**（包含独立审查后的退出与异常元数据补充）。

新 UI 场景覆盖：三算法入口、v2/v3/v4 偏好保留、设置与刷新分离、候选 tooltip、不阻断质量建议、平场失败提示、5 帧去重及预算释放、预览、采集中换源与关闭、光照 2 Hz/单在途、中文指标、完整/损坏参考 ZIP。既有试验工作区、候选交互和记录测试同时通过。

独立审查追加并修复：

- `QDialog.reject()` / Esc 隐藏不一定触发 `closeEvent`；窗口现在通过 `hideEvent` 与 `closeEvent` 共用幂等清理，停止定时器、取消后台准备并释放采集中租约。
- 光学窗口接管 Esc 的 `ShortcutOverride`，避免宿主“取消测量草稿”快捷键抢走按键。真实 `QTest.keyClick(Escape)` 验证采集半途关闭后无隐藏检查，原手工草稿保留；后台任务未退出时重开仍只有一个在途任务。
- 成像元数据非有限值（如 `exposure=NaN`）在申请租约前给出轻提示，不泄漏帧或工作区预算，不让定时器连续抛出异常。
- 同一静态帧重新分析时，依据分析任务/诊断身份更新文字，不额外执行光照检测；新出现的“平场校正未应用”及时显示。

其中候选与帧场景使用受控输入，部分分析提交用替身记录调用；它们验证界面与生命周期契约，并不测试真实相机画质、相机帧率或算法精度。真实导航和完整算法工作进程验证由本轮其他验证记录单独提供。
