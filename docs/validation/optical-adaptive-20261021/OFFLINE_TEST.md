# 普通光学适配 · 0.4.10 离线试测

本包保留传统全图为默认，新增“普通光学适配”。两个 CU 兼容算法没有重算或替换。版本仍为 0.4.10，请用交付清单的构建 ID 和 SHA256 区分。

**快速检查通过后提供试测；真实普通光学样本效果待验证。** 合成图和虚拟机验证不能替代 Microview 实机计量验证。

## 选择算法与试测

1. 打开现有项目或新试验，连接相机，确认标尺和类别。保留一份项目备份供对照。
2. 打开图像上方“全图分析／刷新候选”右侧小箭头，选择“普通光学适配”。首次仍为传统算法，不会自动替用户改选。
3. 在“普通光学设置”中先使用“深浅混合”，保持空白平场关闭。分别用深色实心、浅色实心、浅芯深边及混合视场试测。
4. 手动刷新，或启用“自动”等视场稳定。核对线段是否跨过两侧外边缘，特别关注细纤维端部、两根平行纤维、交叉处和透明芯。
5. 按当前类别连续点击候选；低对比等质量信息只在悬停和诊断显示。原有越限及疑似重复确认保留。互斥解释可能同时展示，由用户决定采用哪条。
6. 留置稳定视场，开关菜单、连续点选，确认余下候选不会整组刷新。再次验证混合模式的“两点测量”和“按住拖线”均按各自手势工作。
7. 打开证据相册，确认已接受测量的局部图片仍来自原始测量帧；保存项目、重开，并导出 Excel 报告。
8. 用同一静态原始帧切回“传统全图（CU 兼容）”对照。原“多尺度全图”现名为“玻纤多尺度（CU 兼容）”，计算逻辑不变。

## 可选空白视场校正

1. 保持物镜、相机、分辨率、曝光、增益及光照一致，移动到载玻片没有纤维的空白区域。
2. 在“普通光学设置”采集五帧空白参考并预览。残留纤维、过曝或无有效亮度时先改善条件再重采。
3. 启用参考并“保存设置”，移动回样品后刷新候选；也可使用“应用并刷新候选”。普通保存只影响下一次分析。
4. 平场只作用于普通光学算法的检测副本，不改变预览和证据图片。已知成像条件不匹配或参考缺失时显示“校正未应用”，仍允许不校正分析。
5. SDK 未提供的曝光、光路或灯光变化无法自动识别；改变这些条件后请重新采集参考。校正不是对焦或图像质量保证。

## 无网络设备反馈

- 从“光照检查与诊断”导出 ZIP；包含参数、光照指标、当前分析诊断，以及可用时的空白参考文件。坏图或缺图会记录原因。
- 从全图分析菜单导出离线性能诊断。记录所用构建 ID、相机分辨率、标尺、手工手势和算法名称。
- 对识别不佳的视场，另存未标注、未压缩的相机原始 PNG；截图不能代替原始帧。保留理想测量线的截图或说明，注明深色／浅色／混合、失焦、曝光等实际条件。
- 后续原始图像将区分开发样本与独立验证样本，报告漏检、拆分、错误合并、重复及宽度误差，不仅比较候选数量。
