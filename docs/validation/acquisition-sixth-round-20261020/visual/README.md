使用 `scripts/validation/validate_round6_compact_ui.py`，在 macOS Qt `offscreen` 环境运行四主题、四组尺寸/DPI，共 **16 项通过**。应用保持 **0.4.10**。结果见 `matrix.json`，各项字体、设备像素比、控件几何及相关源文件 SHA-256 见 `reports/`。

```sh
  --output .tmp/acquisition-sixth-round-20261020/compact-ui --matrix
```

检查经过实际主导航、采集子导航及鼠标点击。为隔离视觉问题，试验类别和标尺通过测试配置准备，采集图像使用模拟设备。

全部场景确认：

- 相册按钮为 40×22 逻辑像素，图标为 16×16；箭头区域为 12×22，与图标显示空间分开。
- 主区点击打开非模态相册；箭头仅打开菜单，不误打开相册。
- 打开相册前后类别滚动区几何不变，保存及 Excel 导出入口可达。
- 无窗口尺寸被控件最小尺寸意外撑大，无未捕获 Qt 槽异常。
- 1600×900 的 100%／125% 满足至少六类／四类的现有要求。
