完整回归启动后仍有最后的短状态文案及对应测试调整，因此不将初始全量运行描述成最终文件的一轮全绿。最终 410 项和真实导航验收分别验证冻结后的相关源码；不同阶段有重复覆盖，不相加为测试总数。

Windows 后续定向检查又暴露出记录测试夹具的时钟精度假设：一次紧密循环创建的记录可具有相同时间戳，产品既定的“时间＋记录 ID”排序不保证这些记录按创建插入顺序排列。原 6 项中有 5 项因此失败。只将测试数据改为明确每条递增 1 ms，并新增同时间戳按 ID 确定排序、不丢记录的用例；产品排序未改，全部原有滚动／生命周期断言保留。本地相关 29 项通过，Windows 定向复核结果见总交付报告。

手工首点覆盖混合／仅手工、自动开／关、首次／已有成功记录共 8 种组合，每次 1,000 次无按键移动。自动实际开启的工作进程场景另见 [手工录像与事件轨迹](../manual-input/README.md)。鼠标移位释放、持键拖动、同点、双击、丢失抓取、旧失败及同批状态变化均有专项断言。
