# CU 兼容范围与有意差异清单

本清单将已保留的算法、明确修复、容量扩展、交互调整，以及未实现／未验收的范围分别列出。依据包括 CU5／CU6／CU6 免脱色留存的源码恢复、原图和调用 JSON、本项目代码与验证报告；没有为编写此文重新运行原软件或任何性能负载。含量对象是 `CMsgAdmin2`，普通非冻结 `CMsgAdmin4` 的字段与状态不混用。

方法标签沿用原软件，不代表标准认证；软件对照也不替代真实显微样本计量验收。公式全文见 [含量计算说明](../../cu-content-calculation.md)，操作对应见 [CU 操作过渡](../../cu-live-transition.md)，总验收见 [REPORT.md](REPORT.md)。

## A. 保留的计算与行为

| 编号 | 保留项 | 已有证据 |
|---|---|---|
| A01 | 人工贴边的取点、整数灰度、阈值、连通域、边缘追踪顺序、拟合、角度约束及平均垂距；失败不自动改自由测量 | macOS 与 Windows 均通过 246／246 原金样；其中 192 个成功结果 double 按位一致，其余拒绝状态按金样核对 |
| A02 | 传统全图候选圆、`C²` 关系矩阵、排序、连接、筛选与直径采样；多尺度 Mid → Cu → Thin 三个 pass | 两平台 177 组中 175 组严格匹配，另 2 组为下述 C01 容量扩展；候选、中间图像和内部 pass 计数无未解释差异 |
| A03 | 窄 OpenCV 旧语义：旧灰度 AA 绘线、旋转卡尺 float 运算与凸包顺序、L1 拟合最佳解更新时间 | 恢复首个分歧点后，额外 33 个完整中间阶段一致；没有通过改筛选阈值或候选排序掩盖差异 |
| A04 | 原参考图与当前图的暗像素重心／普通相关位移检查，以及相邻图差分与 Sobel 检查；生产采用 CU6 缩小尺度 | 111 组运动参考结果；B01 单列故意修正的强变化计数，不能把修正模式也称逐项等同原版 |
| A05 | 11 个含量方法标签与实际权重、原始／分组数据域、苎麻上端／中值区别、FZ/T 30003 经验修正与首项残差 | 176 配置独立 Decimal oracle；恢复阶段原软件另有 24 值对照，20 按位相同、4 差 1 ULP，不能混成 176 次原软件实测 |
| A06 | 当前方向、经纬重量混合、多人纤维／织物三种不同层级；有姓名参与者作多人分母，纤维报表使用经向 | 公式及完整经纬记录证据；稳定 ID 对齐属于 D04 的设计改进 |
| A07 | 普通两位与免脱色一位汇总、首类残差、原始单样本方差缺失和分组单样本方差为零的区别 | 两模板仅 54 个最终汇总公式不同，另外 14,349 个 formula token 相同；原始单样本方差法明确未就绪 |
| A08 | 连续实时画面、当前视场与历史分离、移动清当前标记而保留已入账历史、先选／后选、九类颜色编号、独立补计数、经纬与最多三人 | dialog 324 原始资源、留存真实窗口树、原界面 13 项历史操作验证；本项目另有真实 Windows QTest 操作和布局验证 |

A01–A04 的详细证据见 [人工／运动／捕获报告](../cu-manual-motion-capture-20261015/README.md) 和 [全图／发布报告](../cu-automatic-and-release-20261015.md)。历史原版探针是留存证据，不能写成本轮重新运行原 CU 的结果。

## B. 明确修复，不宣称与缺陷保持相同

| 编号 | 原问题／边界 | 当前处理与范围 |
|---|---|---|
| B01 | 相邻图 Sobel 强变化按有符号字节统计，只计 71…127，漏掉 128…255 | 生产按无符号值 `>70` 统计；111 参考用例中 12 项是这项有意差异。检测阈值本身不另调参 |
| B02 | 传统全图直方图先执行 int32 的 `hist[i]×i` 再转 double，大图亮背景可能溢出 | 先转 double 后乘；真实 4096×2730 回归与独立整数 oracle 覆盖。正常域 177 金样保持既定结果 |
| B03 | 原始统计／分组频数读取长度不同，固定 201 桶使部分已测数据未纳入 | 全部记录与动态分组，详见 C02；不把原有错误输出作为大样本目标值 |
| B04 | VBA `RoundN` 的严格容差比较在精确边界处没有赋值 | 将边界纳入奇偶舍入分支；保留容差单位与其余分支，不换成普通四舍五入 |
| B05 | 缺密度、只计数、原始单样本方差、零重量等会产生空字符串、FALSE 或 Excel 算术错误 | 明确“未就绪／无效”及原因；没有足够输入就不发布假百分比。恢复为零的三类棉密度保留为零 |
| B06 | 留存原程序曾发生两次有应用错误事件的自动视场访问冲突；静态代码还有退出完成标志与 OS 线程退出不等价等风险 | 新来源具有代次门禁与明确停止结果；停止失败保留资源引用，禁止开第二来源或直接销毁。并不声称已经逐一复现、定位和修复原 CU 的两个崩溃根因 |

## C. 容量扩展与显式资源上限

| 编号 | 有意变化 | 边界 |
|---|---|---|
| C01 | 移除旧 CU6 传统算法固定 30 根输出截断 | 两个 `many_35.bmp` 用例返回 35，前 30 与 CU6 一致，全部 35 与相同输入的 CU6mt legacy 一致；不是任意新增 5 个结果 |
| C02 | 原始 1,500 格、分组 1,488 格和 201 桶改为完整记录、动态桶 | 1487／1488／1489、1499／1500／1501、3000 条及超过 201 桶有回归；旧软件超过 1488 条的真实 GUI 运行未完成，差异依据为模板静态公式与独立 oracle |
| C03 | 明确全图候选、超时和内存限制，耗尽时拒绝整个任务，不给可入账的半批结果 | 默认 10,000 候选、30 秒运行硬超时、2 GiB 算法预算；传统最坏平方关系仍在，未换成近邻近似 |
| C04 | 为高频帧引入保留帧／采集预留、最新帧邮箱与背压 | 默认 512 MiB 帧预算包含所计独立帧 owner 与来源声明的 CPU／GPU 帧负载；不含 `cv2.imencode` 压缩输出及 Qt／驱动全部分配。原计划总缓冲预算尚未完整落实，不能把账本峰值当作总内存已达标；RSS 另报 |
| C05 | 原始图按实际尺寸无损保存、同帧记录共享证据，失败状态可保存且可明确放弃原图 | 保存原图默认开；后台未结束时不冒充已落盘。证据路径与摘要去重、重开校验，不以截图缩略图替代原始 8 位像素 |

## D. 为平滑过渡保留和调整的界面

| 编号 | 当前行为 | 与 CU 的关系或防误操作目的 |
|---|---|---|
| D01 | 中央实时画面、右侧最多九行类别；各行独立加减、原始均径、当前方向含量、实测数 | 保留高频布局；原左侧历史改为下方“当前视场／试验历史／全图候选”分页；高级参数折叠 |
| D02 | 新试验默认含量、贴边、两击、先选、数字键选类、经向、保存原图；初始绵羊毛／山羊绒 | 默认和开关外显；拖动可选。数字键模式替代 CU 裸 Ctrl 隐式切换；文本输入不抢数字，自动重复不补计 |
| D03 | 后选绑定本场当前人／方向最新测量操作 ID，可在计算、核验、待确认阶段改类 | 保留“测后选类”的连续性；取消／失败后不回落到上一条。右键先取消草稿再显示非模态菜单 |
| D04 | 材料以稳定 ID 跨人／方向匹配，操作者可改名且身份不变 | CU 按类别名匹配；这是防同名误混、改名拆组的设计改进，不是原名称合并的逐字复刻 |
| D05 | 真正撤销／重做测量、补计、编辑、删除及改名；未完成手工操作时先提示处理 | CU“恢复”实际删除最新记录；不沿用容易误解的名称。单纯候选计算和已入账原图写盘不阻塞撤销 |
| D06 | 越限区显示 ID、类别、直径、范围，橙色虚线标记“未入账”；保留／改类／放弃对应显示 ID | 不自动用直径认材料；最新后选与首个待确认不是同一条时明确显示。已入账后选越限保留原类并警告，可通过记录编辑明确修订 |
| D07 | 全图先产生候选，逐项或批量赋类；勾选接受、明确排除，越限需逐项授权，确认后整批入账 | 候选尚未计数／计含量；不能把全图运行完成等同于测量已接受 |
| D08 | 操作者／方向／来源／标定改变时隔离旧请求并结束当前场 | 历史保留；改变方向无需照搬 CU“先手动新视场才能切换”的限制 |
| D09 | 提交前覆盖当前最新已显示帧的运动核验；两秒追不上就明确拒绝 | 不能凭某个旧帧已稳定而把之后未核验画面对应的结果永久入账；这会影响高分辨率动态吞吐，按真实失败分母验收 |
| D10 | 预算压力暂停新测量／确认、继续最新预览；纯背压不清除已确认本场标记 | 来源身份变化仍立即隔离旧标定；内存不足不伪装成载物台移动 |
| D11 | 当前图片采用原始 8 位像素；非 8 位需用户明确转换；外部窗口单独标定 | 不用调色后显示图暗代测量原图。贴边／全图要求等比例标定；非等比只在主动选择自由测量时支持 |
| D12 | CSV 是原始记录／补计数账本；Excel 另含当前统计引擎的方向、混合和多人汇总 | 无 Excel COM 依赖，不逐格复制 CU 工作簿公式。JSON／项目为主保存格式，含设置、快照与可选证据 |
| D13 | 另一个顶层窗口盖住 CU 时继续捕获正确的目标窗口像素，而不是一律暂停 | WGC 取得目标 root 内容后裁剪 child，PrintWindow 兼容路径直接请求目标绘制，均不退回桌面 BitBlt；受控遮挡验证通过。这是对计划“遮挡暂停”的明确调整，目标内部菜单／同 root 子控件遮挡仍未验收 |

普通／免脱色 `profile` 只影响含量汇总舍入；不会同时切换视场检测的缩小倍率。当前生产选择 CU6 检测尺度并修正 B01，不宣称同一个开关复刻了三版 CU 的所有行为。

外部捕获在 root／child 不可见、最小化、DWM cloaked、关闭或身份变化、裁剪越界，以及三秒无新到帧／序号不前进时暂停；PrintWindow 还拒绝黑帧／超时。错误后关闭捕获，用户需重新连接，受控探针中的“恢复成功”不表示工作区会自动重连。真实 CU 驱动停止渲染的表现尚未验收。代码依据为 `native/windows_capture.cpp`、`live_experiment/sources.py` 与 `live_experiment/window_capture_helper.py`。

## E. 未实现与未验收，分别列明

**本轮未实现或明确不纳入：**

- 导入旧 `.UV_手动含量实验`、复刻旧 Excel 模板和 COM 工作簿自动化。
- 自动认定材料、根据直径越限直接换类、自动平台控制，以及借本轮改写原有模型快速测径／面积识别链路。
- 非等比例像素的贴边拟合／全图物理坐标重定义；不以未经原证据支持的公式替换现有算法。
- 随普通／免脱色汇总开关同时切换旧版本的全部运动检测差异。

**首轮正式快照后发现并单列修正的设置路径：**原设置确认在过滤未变化字段前遍历记录，真实改宽和其撤销／重做又在 GUI 全量重建；API 允许自定义组距，但下拉框不能保留列表外的值。新增修正将未改变组距提前过滤，方法／提醒独立更新不扫描历史；界面保留加载的自定义宽度，实际改宽及其撤销／重做改为记录引用快照→后台聚合→版本核验后原子应用。期间仍可显示和测量，数据变化会拒绝旧结果并提示重试；取消／关闭保留 owner 直到任务退出。普通单条增量、controller 入账身份、运动、测量内核均未改动。

这项修正与此前采样／包是不同源码身份，详见 [configuration-rebuild-overlay.json](configuration-rebuild-overlay.json)。模型与公式专项先通过 250 tests；统一 R2 相关回归随后通过 812 tests／57 subtests，已覆盖工作区异步、绘制、取消关闭、自定义组距和第二设置对话框门禁。原配置阶段 SHA 与运动调度调整后的测试 SHA 分别保存；新版包与大账本设置响应另验。快照只复制不可变记录引用，收集仍为 O(N)，不能描述为整个设置流程 O(1)；同步领域 API 为非 GUI 调用保留。既有 `final-*.json` 不改写，也不拿原结果代替新增配置路径证据。

**已有代码或部分证据，但仍不能宣称验收完成：**

- 真实显微相机／采集卡、Microview 硬件、实际 CU 窗口及真实载物台运动录像。WGC 9／9、PrintWindow 8／8 是受控窗口与 Windows 冻结探针，覆盖遮挡、位置、缩放、最小化等情况，不能替代这些设备。
- 真实显微样本的准确度、重复性、操作者差异、标准符合性；恢复算法和合成金样不是物理计量验收。
- 全部分辨率和联合负载的高频性能。[首轮 PERFORMANCE.md](PERFORMANCE.md) 中两平台高分辨率动态输入出现核验超时或未达延迟门槛，不能只报成功样本耗时；后续修正与真实 Qt 一小时按新版身份单列于 [R2_PERFORMANCE.md](R2_PERFORMANCE.md)。早期无真实画布的控制器 soak 不作正式一小时证据，旧样本也不能冒充新版复测。
- Parallels Windows ARM64 上运行 x64 Python／应用的仿真结果不能直接代表原生 Windows x64 设备。macOS offscreen 的 QPainter／QTest 结果不等同物理屏幕呈现。
- 同一内部安装器已完成解包逐文件核验、真实冻结自检和 GUI 入口／自然退出验证；未注册式安装／卸载，未替换原设备已有应用。

最终回归、源码摘要和包身份以 [REPORT.md](REPORT.md)、[发布记录](../cu-automatic-and-release-20261015.md) 为准。此清单不把功能存在、算法对照、性能达标和真实设备验收混成同一个“完成”。
