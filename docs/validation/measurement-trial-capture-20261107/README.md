# 测量标注、批量属性、含量换样与实时抓拍

本次源码验证以 `7cd6b20` 为基线，软件版本为 **0.4.14**。

| 使用场景 | 操作和结果 |
| --- | --- |
| 查看尺寸 | 新建直径标注默认仅显示数值与单位，例如 `10.00 mm`。右键“标注属性”可以加回编号、指标名称或符号，也可选单双引线。点击“确定”修改当前对象，显式选择“设为同类默认”才影响以后新建的同类测量。 |
| 放置标注 | 用鼠标拖动结果文字，松手记录一次移动；Esc 取消。打开“结果文字与测量线平行”后，有唯一尺寸方向的文字随线旋转，双端引线仍指向两个实际端点。专业标注响应“图像像素／屏幕自适应”，画布与导出共用布局。 |
| 批量编辑 | 在记录表用 Ctrl 或 Shift 选择多条记录。右侧类别可直接统一归类；在属性面板修改需要的字段后点“应用到所选”，一次撤销整批更改。“多种值”表示所选对象的值不同。 |
| 结束含量试验 | “结束并换样”列出当前样品与记录数；点“移除并开始”后从当前项目移除这一份试验，继续在空白样品上工作。其他试验及测量文档保留。要保留当前样品再新建，可用“切换 → 新建并保留当前”。 |
| 连续拍照 | 采集中每次点“抓拍”，使用同一设备会话的下一张完整帧。图像加入当前项目后，页内显示“已抓拍第 N 张 · 查看”。留在采集页可继续拍，点“查看”才进入测量分析。 |

## 标注松手的逐帧验证

混合面积和手动线段时，面积启用了后台绘制的测量瓦片。修复前，松手后第一次重绘仍可能显示旧文字和引线。修复后拖动使用单独的预览对象，不改文档；松手提交一次，旧瓦片与新瓦片交接期间继续显示最终标注。

独立测试推迟部分瓦片的交付，在每个绘制阶段从旧文字区和新文字区取样。在普通图像和非零全局原点的切片上，分别验证了线段单引线、线段双端引线和面积标签。真实主窗口另外验证 Esc 时序列化内容与历史保持原样，释放后撤销／重做一次即可准确恢复两个位置。[修复前复现](local/before-fix-label.log) · [画布回归](local/canvas.log) · [真实主窗口历史记录](local/label-history.log)

## Windows 11 源码验证

在独立目录加载与源码匹配的原生内核。最终快照包含当前工作区已有的 DSX 文件，以模拟帧运行测试，未连接采集设备。最终 **247 项定向回归通过**。100%、125%、150%、200% 四档缩放各检查亮暗主题、常规窗口和 1067 × 600 窄窗，共 80 张截图通过哈希复核。[Windows 汇总](windows/summary.json) · [测试日志](windows/219f308b6ff6/regression.log)

首轮截图中，试验侧栏自己的样式覆盖了两个按钮的颜色。修正后，125% 下浅色／深色入口分别有 660／663 个警示色像素。确认键有 4599／5664 个像素使用移除色，“取消”键没有移除色像素。四档结果都显示斜向标注为 `10.00 mm`、方向约 −53.13°；抓拍和换样共用一次相机启动。[125% 界面验证](windows/219f308b6ff6/dpi-1.25/result.json)
