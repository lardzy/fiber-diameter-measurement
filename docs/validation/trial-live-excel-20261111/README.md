# 试验类别、限值与 Excel 实时写入验证

日期：2026-11-11。源码版本 **0.4.14**，工作区基线 `e3d438c2cfa316c0c093ffa1e57b927418ba671e`。验证完成后仅将本次相关修改及报告提交到本地，不推送或构建安装包。保留同工作区独立的 DSX 修改；测试图片、Excel 副本和原始日志在本地 `build/trial-excel-20261111/`，不纳入 Git。

## 结论

类别库、直径范围、数量目标和两种试验的实时 Excel 流程已实现。顶部 **试验 → 纤维类别库…** 与试验页工具菜单共用一个入口。用户提供的 `sheet11.xlt` 已在真实 Windows 桌面 Excel 中验证，可以按现有含量映射使用；文件名不是匹配条件，原文件未修改，也没有擅自替换用户的默认模板。

功能回归通过，**500 ms 的常规可见延迟 P95 目标尚未达到**。最终虚拟机样本的含量／直径 P95 分别约 **1175／1138 ms**。原始数据写入与报表计算完成分别报告，不能拿较早的写入回执代替可见结果，也不能把模拟传输的界面测试当作真实 Excel 验证。

操作说明见 [试验类别、测量限值与 Excel 实时写入](../../trial-materials-live-excel.md)。模板、原生工作进程和异常恢复的具体证据见 [Excel 工作进程验证](excel-worker.md)。

## 实现覆盖

- 类别库使用稳定材料 ID，管理名称、别名、密度、范围、建议类别和来源。公共默认与试验参数副本分开；有记录或待确认结果引用的类别不可直接移除。修改库不会追改旧试验。
- 含量按类别范围判断；直径使用整场独立范围。边界允许通过，越限由用户决定；改径、改类也重新核对，并记录当时范围与处置。新试验范围及目标的默认值按两种试验分别保存。
- 达到数量目标提醒而不阻止继续。含量单类实测与本方向总根数（含补计）分开；直径按当前操作员有效实测。删除、撤销和重开走原有进度机制。
- 应用级 Excel 协调器按试验 ID 保存关联，页面成功进入后异步建立工作簿。切页复用、关闭后停止、显式重新同步全量恢复。新增、改径、改类、补计、删除和撤销同步；图像写入进度不重写输入。
- 约 100 ms 合并输入变化，一个在途请求与一份最新待处理状态。已确认的快照生成差异，修改和删除清除旧尾部。工作进程请求带试验 ID、关联代次和输入修订。
- 工作副本的受管输入区添加无密码保护，报告区可编辑；用户保存及另存由工作簿对象持续跟踪。停止同步、换样和退出释放关联及新增保护，保留用户工作簿。同步状态与磁盘保存状态分开。
- 最终同步支持等待、重试或明确结束未同步关联；取消预检保留当前试验。强制结束许可只适用于当时的试验修订，解除关联的重复轮询保留忙碌原因。
- 沿用系统 PowerShell 5.1 STA 和既有依赖，未添加 Python COM 包。生产工作脚本已加入 setuptools 与 PyInstaller 数据文件清单；只是核对构建配置，没有制作安装包。

## 原生性能结果

脚本 `scripts/validation/verify_trial_live_excel.py` 在工作簿已打开后，各连续提交 20 次记录，检查真实工作进程回执和原始数据／计算结果。P95 使用排序后第 `ceil(N×0.95)` 项。新增记录到 `inputs_written` 是写入回执；最终回执在计算和恢复屏幕刷新之后，作为保守的报表可见边界，未做屏幕光学计时。

| 最终运行，毫秒 | 含量（用户 sheet11） | 直径 |
| --- | ---: | ---: |
| 首次建立工作簿 | 8927.73 | 1930.36 |
| 原始写入回执 P50 | 475.52 | 236.12 |
| 原始写入回执 P95 | 786.06 | 908.08 |
| 计算完成／恢复显示 P50 | 841.34 | 432.50 |
| 计算完成／恢复显示 P95 | 1174.88 | 1137.72 |
| 计算完成／恢复显示最大值 | 1483.32 | 1284.36 |
| 增补到 300 条并完成计算 | 775.07 | 480.50 |
| 超容量状态写入并完成计算 | 1502 条：808.21 | 2977 条：1183.39 |

500 ms P95 未通过。已经取消持续写入期间不必要的状态查询，但本轮最终数据不能支持“已经达标”或“该优化一定缩短延迟”的结论。优化前隔离运行的可见 P95 为含量 991.28 ms、直径 1133.02 ms，原始记录在 `native-isolated-before-poll-fix/`；更早存在并行压力的运行保留在 `native-concurrent-first-run/`，不用于达标判断。虚拟机调度和 Excel 计算的波动尚需在现场电脑上复测。

模型入账＋发送异步更新的调用耗时 P95，开启同步为含量 0.065 ms／直径 0.048 ms，关闭对照为 0.218／0.184 ms。它只是 Python 调用段，存在预热与调度噪声，**不能推导完整测量交互更快，也不能据此验收真实相机交互回退不超过 10%**。主线程没有同步等待 Excel，但现场相机及完整 UI 延迟仍待验收。

最终专用 Excel 进程工作集 **523.82 MiB**、峰值工作集 **820.87 MiB**、私有内存 **219.07 MiB**。该值包含同一 Excel 进程中的两本测试工作簿，不是 FDM 内存，也不是单张报表的独立内存。进程身份和精确字节数见本地 `worker/root-final-native-memory.json`；此前运行的记录独立保留在 `worker/root-final-stress-memory.json`。验证结束后按 PID、启动时间及两本工作簿名核对，仅关闭本轮专用测试实例。
