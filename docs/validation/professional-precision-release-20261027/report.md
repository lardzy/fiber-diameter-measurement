## 改动与使用方式

1. 打开“设置 → 专业测量”，设置“结果文字小数位”，可选 **0～8位，默认2位**。页面位于“测量与显示”之后，双端尺寸预览即时反映当前草稿值。
2. 点击“应用”或“确定”后，已打开的普通图像、数字切片及后续打开图像的专业标注使用该精度；重启后保留。取消不应用尚未确认的草稿；“恢复本页默认值”将本页草稿恢复为2位。
3. 使用固定小数位并保留末尾零，如2位时 `266.55098 → 266.55`、`25 → 25.00`；舍入后的负零显示为 `0.00`。无效测量继续显示原因。
4. 画布、标注命中区域、拖动背景、自动排布和图像导出的专业标注使用同一格式。已保存的手动偏移保持原位，改变小数位不重新找边或修改测量值。
5. 专业结果表／详情继续显示8位有效数字，CSV／Excel保留计算值。新设置仅保存为应用偏好，不写入项目或 `.fdmslide`，不增加测量撤销记录或使项目变脏。
6. 旧“测量与显示 → 直径/长度结果”中的端点样式、未分类测量线颜色已与结果文字设置合并，紧邻预览；它们仍独立于本页的专业标注精度。
