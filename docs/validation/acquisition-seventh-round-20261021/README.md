# 第七轮采集与试验验证

版本保持 **0.4.10**。本轮以第六轮未提交工作区为基线，修改候选生命周期、混合模式命中及换场点选标记。没有修改现有视场检测或测径算法。

## 行为变化

- 候选以来源、视场及标定上下文为有效期；实时采集中不再创建独立候选对齐任务或按每帧核验时限隐藏候选。既有视场检测、接受前的来源/范围/重复检查仍保留。
- 鼠标按下时绑定实际绘制的命中；已失效的可见候选点击及双击不能降级为手工首点。手工草稿与候选批次刷新分开。
- 仅画布点选成功入账的标记，在运动换场或“新视场”后原位保留，默认 1 秒，可设 0～10 秒。多组分别计时；不续期、不参与命中、不持有图像帧，也不保存进项目。

新行为明确采用现有视场判定的精度边界，不再承诺每个实时帧与候选分析源帧满足原独立像素对齐阈值。候选测值和测量证据仍来自原分析帧。独立对齐模块保留用于既有离线安装自检，不参与实时测量。

保留层的隐藏与上下文重置区分处理：单纯隐藏控件时倒计时继续，到期不重播；现有真实页面导航会同时退役试验帧源并结束上下文，因此清理保留组，不承诺返回页面后恢复尚未到期的旧组。运动换场与“新视场”按钮才创建限时保留组。
