# 第七轮离线 Microview 快速试测

版本保持 **0.4.10**，请用随包清单中的构建 ID 和 SHA256 区分候选。此包先经过必要快检交付，完整回归随后进行；Windows 虚拟机、模拟图像和实体 Microview 结果分别记录。

先保留此前可用安装包及实际项目副本。记录 Windows 版本、屏幕分辨率/缩放、相机型号、取帧尺寸、所选全图算法和存档方式。

| 步骤 | 操作与应观察结果 |
|---|---|
| 稳定候选 | 进入含量试验，完成操作者、类别和标尺准备，开启自动分析。固定画面 60 秒，并打开/关闭菜单：只分析一次，已有候选不因逐帧核验而整组消失；不再出现原来的“候选核验中”或“候选位置暂无法确认”。 |
| 连续点选 | 连续点选多条候选。只更新点中的条目，其他候选位置、编号和赋类保留；不重复计入。接受全部候选后，不自动重复分析同一视场。 |
| 手工首点 | 混合模式下点击一次空白背景，松开后移动鼠标并静置，不能自行提交。第二次点击才完成；分别在自动开启/关闭、候选存在/刷新时重复。 |
| 候选变化时点击 | 在候选刷新或换场附近点选候选，不能把失效候选点击悄悄解释为手工第一点。已有手工第一点时，刷新候选不能结束或清除草稿。 |
| 换场保留 | 在同一稳定视场通过画布点选并成功计入 A、B、C，随后调焦使视场变化：三条标记原位保留默认约 1 秒，采用淡化虚线；普通候选和手工线不混入。连续调焦不会延长这 1 秒。 |
| 保留时长 | 在“候选显示”菜单调整“换场后保留已点选标记”为 0、1、3 秒分别试测；0 关闭。重启后偏好仍在，不产生项目未保存提示。 |
| 输入不受阻 | 旧点选标记保留时继续手工两点/拖线及新候选点选，旧标记不能截获鼠标或重复计入。撤销、删除相应记录后不继续显示其有效标记。 |
| 新旧视场 | 旧组尚未消失时在新场完成点选再换场，各组按自己的期限退出；切换设备、标尺、操作者或方向，不跨上下文显示旧标记。 |
| 业务和证据 | 保存重开、查看局部 JPEG 证据、撤销重做、导出 Excel 报告。数值、原始测量几何和证据源帧保持对应。 |

异常发生后，尽快从 **“全图分析/刷新候选”旁箭头 →“导出离线性能诊断…”** 保存 JSON，同时记录时间及录屏。输入轨迹有长度上限，不要在异常后长时间重复移动鼠标才导出。提供原始诊断文件、相关项目副本及必要图像证据。

本轮候选以既有视场稳定判定为有效性依据，不再逐帧独立像素对齐；原测径算法和全局视场稳定判定不变。若软件底部仍判稳定但实际发生偏移，请保留原始片段和诊断，不仅提供重启后的画面。

每项填写：通过/失败/未测、构建 ID、时间、诊断文件名。短测通过后，实体设备继续至少 30 分钟采集、测量及存档；实体 Microview 当前为 **待验收**。
