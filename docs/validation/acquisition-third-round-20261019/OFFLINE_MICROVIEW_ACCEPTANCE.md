# 第三轮离线 Microview 验收

本轮产品版本仍为 **0.4.10**。安装包通过同目录的构建 ID、源码清单和 SHA-256 区分；不要仅凭“0.4.10”判断是否安装了本轮候选。虚拟机、模拟帧和真实 Microview 的结果分开填写。此文档列出待执行步骤，不代表相机验收已通过。

## 准备

1. 将候选安装包、哈希文件和本目录一并复制到离线电脑。用 `Get-FileHash <安装包路径> -Algorithm SHA256` 对照交付哈希。
2. 保留当前安装包、配置目录、项目及其同名 `.assets` 目录。用项目副本进行验收，避免覆盖原始样品记录。
3. 记录 Windows 版本、显示器分辨率、缩放比例、相机型号、驱动版本及 Excel 版本。从资源管理器启动安装后的应用。
4. 本轮候选不含面积模型，保留 Microview 组件及内部 CU 报告模板。真实相机测试前先确认画面来源确实是 Microview。

## 操作清单

| 检查 | 操作与通过条件 |
| --- | --- |
| 空白试验 | 进入采集与试验 → 含量试验：不自动选择纤维类别。直接返回采集，无空项目保存提示。通过“新建”和“切换 → 新建”重复检查。已有试验仍恢复原类别。 |
| 样品信息 | 点击样品摘要展开，输入带前导零的编号（如 `0000123`）及名称；收起、跨页、重启后检查展开偏好和已保存内容。 |
| 类别空间 | 1600×900、100% 默认摘要状态至少完整显示六类；125% 至少四类。第九类通过类别区滚动可达。展开信息、150% 和底部停靠时允许局部滚动，保存与导出不能移出可用窗口。 |
| 连续测量 | 配置类别、操作者、标尺后连续测量。失败结果不入账；改变视场后提示消失；接受记录与实时画面位置对应。经纬方向及不同操作者的累计量独立。 |
| 全部记录 | 三位操作者、双方向分别添加实测、正补计及负补计。点击“记录”，默认显示全部数据、时间升序、滚动到最新。补计显示有符号根数，无虚构直径。 |
| 历史浏览 | 在记录中上滚后继续测量：滚动位置不被抢走，出现“新增 N 条 · 回到最新”。点击后恢复跟随。筛选操作不得改变报告范围。 |
| 修订 | 在记录中修改、删除实测并撤销/重做；切到其他操作者后更正一条旧补计，确认更正仍属于原操作者、原方向、原类别，且可撤销。 |
| 停靠与浮窗 | 记录从左侧切到底部、浮窗，再拖回停靠；主、子导航位置不变。浮窗仅在软件内位于主窗口之上，不覆盖其他应用。记录中输入数字不能触发测量补计。 |
| 显示偏好 | 实际像素、适应窗口、百分比、物理倍率在停靠变化、跨页、采集停止/恢复和软件重启后保留语义；实际像素不会因记录打开而自动缩小。 |
| 返回与待确认 | 有已接受记录时返回实时采集，采集继续且记录保留。有候选或未入账结果时返回必须提示；选择留在试验后页面和结果保留。 |
| Excel 高频入口 | 从“操作”页固定底栏直接导出，不先切报告页。输入编号后不主动移走焦点即导出；Excel 保留前导零、全部操作者数据、原模板公式/宏/打印区域。导出进行中继续测量，新记录不混入已捕获的快照。 |
| 导出异常 | 取消文件选择、Excel 导出失败、路径不可写时不显示成功，不覆盖上次成功报告；可打开上次成功文件。报告页诊断可复制、导出到离线反馈目录。 |
| 主题 | 浅色、暖灰、石墨、深蓝及跟随系统逐一检查切片大范围浏览/单视场、设置、记录、候选审核、报告错误状态；热切换主题后文字仍可读，图像和类别标记色不变。 |
| 显示器变化 | 在 100%/125%/150% 与高 DPI 屏幕之间移动；浮窗所在显示器断开后，重新打开记录应回到可见屏幕，位置和尺寸不应把窗口置于屏幕之外。 |
| 持续运行 | 真实动态采集至少 30 分钟，子页切换 200 次、离开采集并返回 20 次。检查无重复设备连接、过期画面、小窗口闪现、导航丢失或持续增长的后台任务。 |

## 反馈资料

每项填写通过/失败/未测，附安装包构建 ID、SHA-256、显示设置及最短复现步骤。布局问题提供全窗口截图；闪窗或停靠问题提供过程录像。报告异常附“报告 → 展开诊断 → 导出诊断”的 JSON。将这些文件离线带回即可，不需要测试机联网。

出现候选问题时，保留失败现场及日志，再恢复备份配置和原安装；不要让旧版本直接覆盖唯一一份新保存的项目。
