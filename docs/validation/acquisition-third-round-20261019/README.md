# 第三轮界面与试验操作调整

日期：2026-10-19。产品及安装器版本均保持 **0.4.10**。本次工作树基线为 `a6426a1`；候选包使用构建 ID、源码清单和 SHA-256 标识，不代表已提交的正式发布。

## 已实现

- 数字切片大范围浏览采用成对的深色半透明底与浅色文字；设置、导出选中项和辅助说明使用主题语义色，候选审核警告随主题更新。不改变显微图像、类别颜色或测量标记数据。
- 含量试验直接进入空类别操作台，不继承预设羊毛/羊绒；保留直径试验原初始化。样品信息使用可展开摘要，顶部编辑区域在受限高度下局部滚动。操作者、标尺、方向、重量及测量方式直接可达，类别独立滚动，数量目标合并到类别行。
- 提供新建、切换、返回采集入口。未配置类别时在首次落点前提示；返回保留已接受数据及共享采集，有未入账结果时明确选择留在试验或放弃。
- 记录面板默认左侧停靠，支持底部、浮窗、恢复默认布局及位置/尺寸/列宽记忆。程序临时隐藏与用户关闭分开处理；浮窗不设置系统级置顶。
- 实测和补计合为时间列表，显式打开时默认全部操作者/方向/类型/视场并滚到最新。上滚暂停跟随，新增数量可一键定位；补计更正追加有符号调整，归属于原记录作用域并支持撤销。记录区域焦点不会误触测量数字快捷键。
- 固定底栏常驻“导出 Excel 报告”和保存入口。导出提交未失焦输入，再捕获全部试验快照；后台继续测量，筛选不缩小导出范围，新测量不污染该快照。成功文件可直接打开，失败保留上次成功报告。

## 兼容与内部边界

试验、记录、统计、标定及项目文件格式保持原有语义。数量和测量算法没有本轮改动。统一时间列表从两个原有账本生成，使用“类型＋记录 ID”定位；相同时间采用确定排序，旧数据的未知时间有稳定回退，不写回旧记录。

新记录布局偏好位于应用配置旁的 `trial-records-layout.json`，版本 1；样品展开状态保存在 `trial-workbench.json`，版本 2，读取旧布局时将原“记录”标签恢复到操作页。偏好、显示方式、停靠和通知状态均不进入项目业务数据。旧记录表模型作为内部适配保留，界面实际浏览使用唯一的时间列表模型。

本轮还处理了回归发现的边界：底部停靠在 150% 小窗口撑高主窗；底停靠切回左侧时的瞬间尺寸约束；停靠后丢失“跟随最新”；展开样品信息进一步撑窗；关闭记录后按钮选中状态未同步；关闭页面后的延迟滚动回调；待提交输入失败后导航未复位。相关回归分别覆盖延迟布局、真实按钮和旧回调清理。
