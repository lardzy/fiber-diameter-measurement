# 第三轮采集与试验视觉回归

日期：2026-10-19。范围：紧凑试验操作台、空类别入口、统一记录面板、固定 Excel 导出入口，以及四套主题下的实际导航与布局。

## 结果与证据边界

最终 **36/36 组合通过**，产生 540 张完整界面截图、36 张单独浮动记录窗口截图。执行 620 次子页导航：浅色 1600×900@100% 连续切换 200 次，其余 35 个组合各切换 12 次。归档保留 19 张精选图、2 段过程录像和全部 36 份结果 JSON。

这是 **macOS 上 Qt offscreen、模拟采集帧、隔离偏好** 的验证。实际创建 MainWindow，通过 QTest 点击主工作区、子页、记录、摘要、标签与返回最新按钮，通过记录“位置”菜单 QAction 执行停靠切换。并未直接改变中央页面状态来跳过导航。

数据使用测试夹具：三位操作者、经纬两个方向、九种已明确选择的类别、168 条实测与 12 条有正负号的补计事件，追加一条实测检查阅读位置保护。候选与拒绝反馈从控制器呈现信号注入。本轮视觉脚本没有检验测径算法正确性，也没有调用 Excel COM。

Qt DPR 为真实设置的 1 / 1.25 / 1.5 / 2；画布尺寸是 Qt 客户区物理栅格，不含系统标题栏与任务栏。非整数缩放的逻辑尺寸四舍五入可能使截图物理尺寸相差 1 像素，例如请求 1600 宽@150% 时为 1601 宽。实际值见各 JSON 的 `physical_client`、`logical_client`、`dpr` 与 `screenshots[].raster`。

Windows 字体/系统装饰、跨显示器移动、原生浮窗置顶、真实 Microview 采集、设备连续运行以及 Excel 模板生成必须另行验收。本报告不把这些项目记为通过。

每个组合检查：实时采集、空含量试验、九类含量、展开样品信息、左侧记录、阅读旧记录时新增、回到最新、底部记录、底部记录且展开样品、浮动记录、报告、候选审核、拒绝反馈、直径试验、返回实时采集，共 15 个主窗场景。

每次场景截图均断言主窗逻辑尺寸未被内容撑大，外层子导航位置及可见性稳定；试验页“导出 Excel 报告”仍处于侧栏内并可见。另检查没有意外顶层窗口事件；允许的记录浮窗单独登记。这能捕获 Qt 顶层控件生命周期问题，不能证明 Windows 原生窗口绝无瞬间闪现。

## 关键观察与修正

- 1600×900@100% 在准备条件完成、样品摘要收起时能完整显示九类，@125% 显示四类；目标列与补计、均径和含量共行，类别区独立滚动。经纬重量、方向、当前直径、测量方式和新视场保持直接可达。
- 新含量试验无预填纤维类别，直接显示“选择纤维类别”。未配置业务内容时没有创建项目内正式试验，“保存”不可用，底部说明尚无需要保存的试验改动。
- 记录默认全部操作者、全部方向、实测与补计、全部视场，并滚到最新。上滚后追加第 181 条记录保持原阅读位置，显示“新增 1 条 · 回到最新”；点击后恢复跟随。左侧、底部、浮动切换后继续跟随最新。
- 早期矩阵发现底部停靠会把小窗撑大、停靠后未重新跟随最新、底停靠切回左侧的瞬间最小尺寸过大、以及展开样品信息再次撑大。最终版本使用底部单行记录工具栏、按可用高度限制记录面板、保存用户正常高度偏好，并让样品信息区域局部滚动；1067×600 下底停靠并展开样品仍保持原窗口边界，保存和 Excel 导出常驻。
- “操作／审核／报告”切换及记录停靠不移动全局两级导航。底部停靠是用户主动分配的画面空间，会缩小中央视口；关闭记录后恢复。小窗口中详细信息采用局部滚动，未依靠撑大整个主窗维持布局。
- 四种主题的主要控件、固定导出按钮、补计正负数、候选警告文字均已结合像素图检查。深色候选的未赋类警告采用主题警告色。本文件仅覆盖采集与试验；数字切片、设置等扩展主题检查由同目录总报告汇总。

## 可复查性

- [36 组合汇总](visual/matrix-summary.json)
- [全部逐组合结果](visual/results/)
- [归档文件校验和](visual/SHA256SUMS)
- 验证脚本：`scripts/validation/validate_acquisition_third_round.py`。
- 运行环境：macOS 27.0.1 arm64，项目 `.venv`，Qt offscreen，CJK 字体详情见结果 `font`。

最终汇总由一次全矩阵及随后 **11 个受源码变化影响的组合重跑**构成。期间仅追加了安全的 Qt 延迟回调上下文清理；留存的 36 份结果全部匹配最终 9 个生产文件 SHA-256，且每份都记录运行期间源码未变化。汇总的 `retried_cases` 保留重跑名单，没有将最初因源码变化失败的矩阵直接改成成功。归档摘要仅把逐组合结果链接改为相对路径；36 份原始结果 JSON 未改写。

完整原始图片、日志与隔离偏好保留在忽略目录 `.tmp/acquisition-third-round-20261019/final-reviewed/`。原始 JSON 中的绝对图片路径指向该目录；归档中的精选图映射见清单。发布时只需归档目录，不需要携带隔离偏好或全部中间图。

复跑命令（需安装 ffmpeg；Windows 可移除 `QT_QPA_PLATFORM=offscreen` 并使用脚本默认平台，但这仍是模拟相机）：

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python scripts/validation/validate_acquisition_third_round.py \
  --matrix --video --output .tmp/acquisition-third-round-recheck
```

聚焦布局回归执行结果：`tests/test_trial_compact_layout.py` 与 `tests/test_quantity_target_dialog.py` 合计 22 项通过。最终延迟回调清理及整体业务回归由同目录总报告记录，避免与本报告的视觉脚本结果混为一项。
