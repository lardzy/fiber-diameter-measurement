# 0.4.10 明确手势试测步骤

本包将手工手势明确分成“两点”与“拖线”。它们和“贴边／自由”的算法选择独立；混合模式中仍能短点击候选直接计入当前类别。版本保持 0.4.10，使用文件名中的构建 ID 区分。请保留当前可用安装包以便回退。

1. 在有 Microview 相机的设备上安装本包，打开原项目或建立临时试验，选好操作者、标尺及类别。右侧测量区域应能直接选择“两点／拖线”。
2. 选择“混合＋两点＋贴边”。在纤维一侧背景单击第一点后松开，移动鼠标或静置；此时只应显示草稿，不应提交或出现测量失败。明确单击另一侧背景后才完成。自动全图分析开、关各重复至少 20 次。
3. 保持“两点”，按住第一点并移动后松开：这仍不应被临时解释成一条拖线。下一次明确点击才完成第二点。选择“自由”重复验证，区分手势问题和贴边识别拒绝。
4. 选择“拖线”。只单击或连续短单击空白处不应留下手工第一点；按住左键拖过纤维并松开才提交。两种算法均试一次。
5. 在两种手势下分别短点击自动候选，均应计入当前类别；候选上的拖动依所选手工手势处理。已有两点草稿时切换手势，应取消未完成草稿，不能补造第二点。
6. 在视场稳定时连续点选几条候选，观察剩余候选是否持续显示；调整视场后观察已点选标记按设置时长退出。保存项目、重开并查看证据，确认已有记录正常。

若仍复现“仅第一点就失败”，请记录手势（两点／拖线）、算法（贴边／自由）、交互模式、自动分析开关、失败提示及当时是否已有草稿。优先保留短录像和应用诊断日志，并注明构建 ID；无需联网。

本轮 Windows 自动化采用 Parallels 虚拟机、模拟相机及 Qt 鼠标输入。实体 Microview、现场鼠标硬件及原始图像的结论需此次实机反馈确认。
