# 第五轮候选包：离线 Microview 验收

本清单用于有真实 Microview 相机的离线 Windows 设备。macOS 模拟输入、Parallels Windows 和实体相机结果分别记录；前两者通过不能替代本清单。版本保持 0.4.10，使用 DELIVERY.md 中的构建 ID 与 SHA-256 确认安装包身份。

## 准备

1. 保留现有安装包及常用项目副本。安装候选包后，在“关于”确认 0.4.10，并记录 Windows 版本、CPU、内存、显示器分辨率/缩放、相机型号及当前采集分辨率。
2. 使用新建测试试验，填写操作者、选择真实标尺和类别。不要用正式业务项目进行压力操作。原始设备设置和常用存档策略在测试前记下。
3. 先关闭自动分析，确认实时画面、标尺、手工测量和 Excel 模板可用。保存项目，再开启自动分析；手工算法保持不变。

## 稳定显示与操作

- 相机和视场静止：候选首次出现后持续观察 30 秒，不应反复消失/出现。打开右侧测量方式、方向、类别等菜单累计 100 次；记录是否出现整组闪烁、错位或旧编号回显。
- 连续移动两次再停稳，重复 100 组。运动中候选应立即失效；稳定后显示新一批候选，不应将旧线移到新纤维上。使用屏幕录像保留出现问题前后至少 10 秒。
- 有“候选核验中，实时画面继续”时，实时画面仍应更新，旧候选不可点击；恢复应整组发生，不能逐帧闪烁。
- 默认混合模式：短点候选按当前类别计入；空白点两次和拖线均能手测；从候选上起拖不能先计入候选。已有手工第一点时，第二点落到候选上应完成手工线。Shift 临时强制手工。
- 对同一候选双击或快速重复点击，不重复增加数量；点按后立刻移动视场/刷新/换页，过期动作不入账。撤销、重做后数量与记录一致。
- 移到无纤维区域，自动及手动刷新均只在底部提示无候选；上一条有效直径保持，不能出现“本次未通过”覆盖卡。

## 存图与相册

- 高级选项“测量与证据”分别选不保存、局部 JPEG、完整无损 PNG；证据按钮菜单应同步。每种接受两条测量，核对只影响之后的记录，之前的图片不改变。
- 点击测值下方“证据相册”：默认全部操作者、全部方向，最新在前。核对缩略图、编号、直径、类别、操作者和方向；双击复核，叠加线应对应真实测量位置。
- 视场已移走时，历史证据仍保持原画面。历史复核不能被新测量替换；向下看历史时新增数据不抢滚动，使用“新增 N 项”返回最新。
- 切换试验不串图；返回实时采集暂时隐藏相册，回到试验恢复。关闭相册不影响采集，重启后窗口位置与缩略图大小恢复。
- 首次打开相册时，标题栏、筛选项及关闭按钮都应在屏幕内；最大化后还原，尺寸应回到最大化之前。分别检查 100%／125% 等实际使用缩放，以及从已移除显示器的位置恢复窗口。
- 保存、重开、另存为后重新检查不同存档模式的记录；未存图无法补回的说明应明确。暂时移走测试副本中的证据文件时应显示缺失，不能显示另一条记录的图片。

## 性能与离线反馈

分别记录同一设备、同一分辨率下的基线（关闭候选）、候选、候选＋相册＋持续存图三组。连续动态采集至少 30 分钟，比较 FPS、P95 帧龄和内存，不只看平均帧率。目标为 FPS 下降不超过 5%，P95 帧龄增加不超过一帧；闪烁另外按显隐转换、最长暂停和恢复耗时判断。

通过图像控制区“全图分析”旁的下拉箭头 →“导出离线性能诊断…”保存诊断。反馈压缩包应含：构建 ID/安装包哈希、设备和显示参数、操作步骤、诊断、问题前后录像、测试项目副本及相关证据。记录真实发生时间，便于对应候选批次、源帧与暂停原因。含样品或客户信息时，可先用专门测试样品复现。

无实体相机、未连续运行 30 分钟、未录制问题路径时，在结果中明确填“待验收”，不填通过。
