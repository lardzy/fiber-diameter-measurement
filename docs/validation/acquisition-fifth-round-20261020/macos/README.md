# macOS 回归结果

版本 0.4.10；平台 macOS 27.0.1 / ARM64，Qt offscreen。相机为模拟输入。产品源码指纹以各运行 JSON 为准；各阶段结果分别记录，早期视觉矩阵不能代表之后新增的进程核验已经受测。

## 自动化测试

最初全量执行：**5442 passed、13 skipped、3 failed**，另有 1653 个子测试通过，用时 756.49 秒，原始输出保留在 [full-tests.log](full-tests.log)。三个失败均已处理：

1. 后选撤销测试构造的自动分析上下文缺少令牌等必需字段。补全真实接口要求的上下文和帧租约，未绕开业务门禁。
2. 两项小窗口测试共同暴露：1067px 窗口先打开左侧记录会被扩为 1068px。取消次要显示方式选择框的固定 108px 最小值，使用字体/样式自然宽度；保留字体和所有主要入口文字。新增左侧停靠后的窗口尺寸及控制矩形不重叠断言。

界面阶段源码上的 [final-targeted-tests.log](final-targeted-tests.log)：**280 passed in 26.25s**，包括上述失败所在文件、候选呈现、混合手势、测量反馈、后选、工作区、相册、记录与紧凑布局。没有将首轮全量结果改写为零失败，也没有把各轮有重叠的用例数相加。Windows 最终目标回归单独保存。

## 界面矩阵（进程核验改造前）

[矩阵汇总](../visual/macos-final-matrix/matrix-summary.json)：**16/16 通过**。四主题分别覆盖 1600×900 的 100% / 125% / 150%，以及 1366×768 的 100%。每例真实导航切换六次，走实际类别编辑、分析进程、候选接受、证据写入、相册、历史复核和高级设置；没有直接注入候选或成功记录。

各尺寸完整可见类别数分别为 9 / 4 / 1 / 5，其余类别通过独立列表滚动访问。150% 缩放下可用逻辑高度较少，不声称四类同时可见。保存与 Excel 导出仍常驻，打开相册不挤压主工作台。

每例保留原始 `result.json`、接受部分候选后的工作台、相册和高级选项三张截图；清单见 `artifact-manifest.json`。完整原始截图仍在 `.tmp/acquisition-fifth-round-20261020/visual-release-final/`。已目视复查浅色完整工作台、暖灰 125% 相册、深蓝 150% 高级选项、深色 1366×768 工作台；另有相册专项四主题截图。未观察到新增裁切、遮挡或深底深字。

## 导航与移动压力（进程核验改造前）

[压力结果](../visual/macos-final-stress/result.json) 与 [过程录像](../visual/macos-final-stress/candidate-evidence-navigation.mp4) 对应当时记录的源指纹：

- 真实下拉菜单开合 100 次，629 个候选可见性采样全部可见，显隐转换 0 次。
- 连续移动后立即再次移动 100 组，重新生成 100 个独立候选批次，无旧批次回显。
- 两级导航切换 200 次，共享采集只启动一次，没有新增意外顶层窗口。
- 真实分析产生九条候选，点击接受一条后其余保留；JPEG 证据写入、相册入口、锁定历史、存档双入口同步及空白手工草稿/Esc 均通过。

录像为 8 FPS 的真实 Qt 控件抓取及应用所属复核窗口合成，约 76 秒；不是整个桌面录屏，不能用它证明 Windows 原生窗口堆叠。该运行同时存在其他构建负载，其计时只作诊断，**不用于性能门槛结论**。性能门槛使用 [独立隔离测试](../candidate-presentation/README.md)。

最后进行了只读交叉审查：核对旧分析/对齐回调、手势按下帧、候选确认队列、防重复、后选目标代次以及取消/关闭的帧租约路径；未发现新增阻断项。静态审查不替代上面的动态结果。

## 最终进程核验与组合回归

Windows 组合压力暴露额外延迟后，将候选核验放入持久子进程，并减少相册及画布重复绘制。保留原测径/对齐数学和阈值；区分核验结果就绪时间与 Qt 消费时间。

- [最终相关回归](final-process-regression.log)：**513 passed、50 subtests passed，32.65 秒**。覆盖真实 spawn、共享内存/资源释放、候选呈现、混合输入、相册、证据、工作区、旧项目、冻结自检及打包门禁。不是重新执行全仓库，也不与此前重叠数量累加。
- [持续 JPEG＋相册短测](final-process-smoke.json)：6 秒负载、每 150 ms 接受一条、之后继续预览 3 秒；30.288 FPS，P95 帧龄 10.51 ms，只有一次初始候选显示，结束预算为零。负载统计不包含后续低负载恢复段。
- [80 ms 核验延迟](final-process-delay80.json)：实际在父端核验任务返回边界注入，覆盖子进程和 IPC；三次显隐变化为首显、暂停、恢复，结束预算为零。没有使用无法传入 spawn 子进程的算法 monkeypatch。

这两次短测验证最终生产路径和诊断脚本，不替代 Windows 最终配对性能、安装版测试或实体 Microview 验收。
