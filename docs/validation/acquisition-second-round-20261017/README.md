# 0.4.10 采集与试验第二轮变更及验证

本轮针对测量反馈、视场切换时的布局、显示偏好、数量目标和 CU 模板报告运行时进行修正。目标交付为 **0.4.10 内部候选安装包，不含面积识别模型，保留 CU 模板**。

**状态：实现、全量回归、视觉检查、Windows 实际安装及启动验收已完成。Microview 真机尚未验收。** 本报告不把源码测试、模拟帧或离线布局检查表述为真机通过。

## 兼容性与保持不变的约束

- 含量计算、有效测量接受条件、标尺换算和模板公式继续使用既有领域实现；新增反馈和目标不把算法失败变成记录，也不以本地统计重写 Excel 模板公式。
- 没有新目标配置的旧项目沿用旧行为；类别的显式目标与“使用默认”分别保留，包括暂未显示的材料配置。旧项目迁移是明确的、可撤销的业务操作。
- 显示偏好、侧栏宽度和提示展示状态不写入试验记录；数量配置属于项目数据。无需业务修改的浏览或显示调整不应触发保存提示。
- 继续遵循进入采集自动启动、离开采集停止、手停后子页切换不重启的路由约定。真实设备启动、停止和重连仍需现场验证。
- 三种模板维持原格式、公式和 VBA；容量不足或模板计数公式范围不足返回需复核提示，不静默截断。真实导出验证使用模板副本，没有更改用户原工作簿。

| 成功入账后底部仍显示旧失败 | 单条与批量接受记录时更新底部反馈和最新有效值，避免成功卡与失败状态并存。 | 视觉脚本显式检查“已计入记录”且不含旧失败；含量 / 直径失败→成功截图与过程录像。 |
| 数量目标对话框不改内容直接确定也变脏 | 保留“继承默认”与显式目标区别，未变更配置保持原结构和 revision；实际更改只产生对应历史操作。 | `test_quantity_target_dialog.py` 覆盖新 / 旧规则、含量 / 直径、隐藏材料覆盖值、键盘恢复默认和无变化确认。 |
| 撤销后旧达标卡仍显示已失效数量 | 计数、目标、名称或范围变化时清除失效达标文字；保留已提醒集合，重做不重复通知。历史操作后最新值跟随账本，全部撤销后清空。 | `test_trial_feedback_history.py` 及最终矩阵真实撤销 / 重做 / 补计按钮操作；不能只以直接调用控制器代替界面验证。 |
| PowerShell 策略拒绝伴随中文乱码 | 主任务与清理统一指定进程级 Bypass，启动引导明确 UTF-8；脚本尚未进入时也能输出结构化错误；读取旧编码输出保留可诊断信息。 | Windows 父进程 Restricted 下真实请求成功，工作进程策略和编码留在 diagnostics；GPO 拒绝仅模拟验证。 |
| 报告失败或取消可能损失原成功结果 | 暂存生成成功后才发布，失败保留目标哈希与上次成功入口；取消和超时独立分类。 | 真实 Excel 失败 / 取消探针验证原报告 SHA-256 不变。 |
| 成功结果先于 Excel 关闭，关闭异常可能被遗漏 | 独立保存 Close / Quit 诊断，必要时走所有权校验清理，不覆盖已生成报告结果。 | 关闭失败单元模拟；真实 15 次导出关闭诊断均成功。没有人为破坏真实 Excel 来验证 COM 关闭异常。 |
