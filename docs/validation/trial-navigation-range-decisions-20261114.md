# 预览入口、含量试验面板与越限裁决验证

日期：2026-11-14。软件版本保持 0.4.14。本轮仅源码修改与本地提交，不制作安装包、不推送。

## 操作变化

- 顶部“采集与试验”的主体始终进入“预览与抓拍”；下拉与“试验”菜单提供预览、含量和直径三个共享入口。相机是否运行不改变导航目的地。预览不创建试验或建立 Excel 关联。
- 返回试验继续使用原试验、记录、参数与 Excel 关联；“查看刚拍图像”进入最新抓拍文档。
- 含量试验完整右栏成为独立停靠面板。可拖到左、右、底部或浮动，顶部“试验面板”可关闭、重新显示和恢复位置。离开含量页临时隐藏，返回恢复用户的显示偏好；直径试验仍使用原侧栏。
- 停靠偏好位于应用设置目录的 `content-trial-sidebar.json`，不进入试验项目。浮窗恢复时限制在当前可用显示器内；底部采用紧凑排列与内部滚动。
- 含量越限结果完成源帧核验后显示居中应用模态弹窗。可保留、改类或放弃；Esc、关闭按钮、移动视场或断流均不取消待确认结果。
- “记住本次选择”按本试验、原类别、高于/低于分别生效，只影响匹配的越限记录。正常尺寸及下一条当前选类不变；自动改类用非阻断文字提醒。规则不写项目或设置，可在操作页“本次越限规则”删除，换样、关闭项目和退出后清除。
- 改类后仍越限需要再次明确确认。来源或目标范围变化、目标不可用时停止自动规则，重新核对。缺失建议类别可在确认窗中打开本试验类别配置。

## 数据与生命周期

已核验结果独立持有源帧预算引用，并固定源视场、图像、标定、端点、测值、操作员/方向、原类别和图片策略。确认时不重新追随当前画面或启动两秒核验计时。未完成计算、未选候选和源帧尚未核验的批次仍执行原失效和超时规则。

确认入账使用原视场和原测量图；若视场已经变化，只更新历史和统计，不把旧标记绘到当前画面。自动候选按已选集合核验、逐项裁决并一次提交，放弃项不写记录、统计或 Excel。普通撤销/重做及图片存档保持原入口，裁决引用在完成或放弃后释放。

直径试验保留原范围确认路径。此前含量手动测量“第一点后视场变化仍保留，第二点使用当时画面计算”的行为保留；本轮从计算结果核验完成后才固定数据。
