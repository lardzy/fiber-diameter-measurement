# 工作区面板与采集画面对齐的本地提交验证

2026-11-06，在 0.4.14 上核对本次提交。为验证与 DSX 并行开发时的独立性，从基线 `70d7669` 提取源码，将属于本次提交的改动放入独立目录。主窗口中原有的六处 DSX 修改留在工作区。逐文件比对确认被测源码、测试、版本文件与 Git 暂存内容一致。

macOS 使用 Qt 窗口、模拟相机会话及合成图像运行联合回归，**358 项测试及 20 个子测试通过**。测试范围、原始输出和逐项结果分别见 [范围](scope.json)、[日志](regression.log) 和 [JUnit 报告](regression.xml)。

| 操作 | 验证内容 |
| --- | --- |
| 测量分析 → 实时采集 → 含量试验 → 直径试验 → 测量分析 | 每页显示允许的面板，返回后恢复测量布局。无文档时禁用测量操作。 |
| 停止预览、模拟断流、切片采集期间尝试切换试验 | 断流后仍在切片采集页，点动停止。进行中的任务阻止切页，空闲时可进入试验；选择“查看切片”回到测量。 |
| 从试验打开图片、文件夹，拖入文件或使用文件关联 | 接受切换才显示新文档；取消打开或选择留在试验时保留原页面与文档。 |
| 在实际像素、适应窗口、百分比及物理倍率下切换对齐方向 | 九个方位按显示偏好保持。手动平移解除吸附，程序调整和相机同尺寸新帧保持既有位置。 |
| 在小 ROI 或极大图像上从适应窗口拖动 | 当前比例与自由位置一起保存，调整窗口及重开后可恢复；写盘失败时恢复上次确认的状态。 |
