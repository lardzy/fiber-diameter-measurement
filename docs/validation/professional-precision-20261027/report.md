# 专业测量标注小数位 · 源码验证

日期：2026-10-27；版本0.4.14。

专业测量标注使用独立应用设置，固定0～8位小数、默认2位，保留末尾零并消除舍入负零。新设置页位于“测量与显示”后；旧线条/端点控制已合并到直径/长度结果预览旁。普通图像、数字切片、标签命中、拖动背景、自动布局和叠加图导出使用同一精度。专业表格/详情8位有效数字及CSV/Excel计算值不变。

## macOS 源码结果

- 38个测试模块，**1,034项测试、182个子测试通过，58.91秒**。范围见`test-scope.json`，原始结果见`macos-regression.log`和`macos-regression.xml`。
- 新精度专项覆盖负零、末尾零、全部量纲、单双引线、宽度/命中/裁剪提示、隐藏标签、拖动缓存、切层，以及真实MainWindow普通图像/切片PNG导出。改变精度时计算值、拟合证据、CSV/Excel、项目字典、脏标记和撤销数保持。
- 实际SettingsDialog的900×640、720×520亮暗主题检查通过，0/2/8位预览和旧端点/颜色/预览同屏；14张截图及哈希见`macos-100/result.json`。使用offscreen插件，不作为Windows或物理显示器验收。
- 设置子任务初次组合运行曾出现macOS/PySide垃圾回收阶段段错误；同一设置命令重跑通过，本次统一回归未复现。保留此边界，不将失败尝试计入通过结果。
