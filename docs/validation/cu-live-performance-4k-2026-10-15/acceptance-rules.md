# 4K 优化复测口径

2026-10-15 按用户补充，以 2K（2048×1365）及 4K（4096×2730）作为本轮正式采样范围。4K 用例面积高于 UHD 3840×2160；既有 6K 原始结果保留，但本轮不再将 6K 纳入达标门槛，也未在软件中新增 4K 硬限制。

沿用 R4 的指标：每条件预热 5 次，正式尝试 30 次，所有失败、拒收及预热拒收均报告。第一击草稿 P95≤16.7 ms、P99≤33 ms；第二击结果可见 P95≤50 ms、P99≤100 ms；GUI 同步发布最大值≤4 ms；30 Hz 输入的不同帧绘制≥27 FPS。并发条件相对同配置原图关闭基线的 P95 增幅不得超过 max(20%,10 ms)。显著换场到标记清除的 P95≤150 ms。

短程仍为每次成功或失败后等待 100 ms，不称为固定 10 Hz。静止与逐帧唯一标记的低位噪声均覆盖；原图关闭、开启及多尺度全图并发分别记录。采样期间主机、虚拟机之间不并行运行测试、编译或其它基准；系统其它活动不宣称被完全消除。

新管线让画布持续绘制完成视场核验的帧。实际 paintEvent 完成后才更新已显示帧身份；点击不改变显示调度。必须同时报告帧龄、不同帧帧率、移动清场和旧结果隔离，不能仅用第二击耗时替代完整体验。检测阈值、灰度和缩小图像、FFT 与 Sobel 结果、测径规则、含量统计与两秒入账核验超时保持原定义。

每轮正式采样期间冻结生产代码；源码摘要记录到每份 JSON。采样后若仍未达标，保留该轮全部原始结果，修订后另建目录重测，不覆盖失败轮次。PNG 对照以本次先提交的 `5049422` 中的实际旧编码器为参考，固定输入交替运行，计入编码、摘要、文件写入、fsync 与原子替换。解码及 SHA 校验在计时之外，文件大小和策略差异同时报告。

与 R4 比较属于同一虚拟机上的跨时段对照，不能当成同时配对测量。PNG 单项则为同进程交替配对。新的全图并发基准在测量采样窗口结束后等待在途全图任务正常返回，FPS 与人工延迟窗口不延长，响应明确标注是否发生在测量采样窗口内；不把收尾取消算作成功。

真实 Qt 压测使用同一工作区、实际 QPainter 和 QTest、原图保存、每十秒换场与传统全图。完整性与性能分别判定，记录 GUI 超过 4 ms 的精确次数。合成帧、Parallels ARM64 内运行 x64 Python 和安装包自检均不替代真实 Windows x64 相机、采集卡或显微计量验收。
