# 0.4.8 真机试用说明

本次提供 Windows 内部安装包 `fiber-diameter-measurement-setup-0.4.8-no-area-models.exe`，保留含量模板和实时试验，不附带面积识别模型。算法结果、两次点击、先选／后选、换场清本场但保留历史等操作规则保持不变。

本轮按 **4K、通常不超过 2,000 根**的使用规模优化和验证，没有给软件新增 2,000 条记录上限。真实相机、采集卡和 CU 渲染画面的表现仍需在对应设备上确认。

## 建议操作

1. 运行安装包，启动软件，通过“试验 → 实时试验”进入工作区。选择当前图片、本机相机或 CU 实时画面。外部 CU 来源需要单独标定；贴边测径要求等比例标定。
2. 选择操作者、方向、类别，用默认两次点击横跨纤维。观察主画面持续更新、结果入账以及失败原因提示；需要自由测量时主动切换模式。
3. 移动视场，确认本场标记和草稿清除，试验历史仍保留；稳定后继续测量。试用数字键选类／额外计数，以及撤销、重做和改类。
4. 在“更多设置与汇总”保持“保存测量原图”开启，按正常节奏完成一组操作；检查历史原图、保存项目、关闭后重新打开项目。可另试关闭原图保存，比较交互差异。关闭只影响后续记录。
5. 按需运行“分析当前视场”，审核候选后确认，观察后台全图运行时人工测量是否流畅。未确认的候选不会自动进入账本。

无需专门跑一小时或万条压力；一份正常规模试验和几次真实换场更有助于发现设备问题。

## 记录实测信息

记录 Windows 版本、CPU／内存、相机或采集卡型号、图像分辨率、显示缩放比例、来源类型，以及原图保存是否开启。若出现卡顿或拒收，记下时间、界面提示、当时是否移动视场或正在全图分析，并保留项目。启动或运行错误的日志位于 `%LOCALAPPDATA%\FiberDiameterMeasurement\logs\startup.log`。

当前虚拟机短程 480 次均入账；持续运行 7,460 条已入账记录及原图全部完整，平均显示 29.57 FPS。不过持续运行中仍观察到少量非预期拒收和 GUI 发布长尾，不能视为所有性能指标已通过。完整实测与剩余项见 [验证报告](REPORT.md)，先在真机上重点确认这些现象是否仍可复现。
