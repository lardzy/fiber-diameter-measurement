# 实时预览与含量非冻结复核

本轮针对 0.4.8 采集重构后的实际反馈修正，继续使用 `lard/cu-live-measurement`，不提交、合并或推送。主要设备为 768×576 Microview。此前的模拟通过不能证明真实板卡的画面质量；原来的包和报告保留用于比较，不作为本轮真机验收依据。

## 图片暴露的问题与代码核对

三张截图可直接看到梳状横纹、遮挡画面的长提示、重复底栏／错位画面、标尺状态不醒目，以及设置页横向溢出。延迟由用户实际操作反馈，单张截图不能测量延迟。代码又确认了以下问题：

| 问题 | 原因及本轮处理 |
|---|---|
| 试验画面等待后台核验 | 工作区启用了 `verify_before_present`。改为最新帧直接绘制；提交记录仍经过最新已显示帧的运动核验，禁止旧场结果入账。 |
| 与旧实时预览像素链不同 | 原生桥登记了 BEFORE_PROCESS，拿到处理前图像并强制关闭 SDK 显示。普通实时采集恢复旧 `native_embed`；试验订阅 AFTER_PROCESS 的处理后原尺寸像素。 |
| 移动时横纹 | 处理前／处理后链路差异是明确缺陷，但实际消纹效果尚需真实板卡确认。没有猜测场模式或增加插值去交错来掩盖问题。 |
| 隐式放大、缩小、平移 | 删除滚轮缩放、中键拖动和双击适配。默认一图像像素对应一物理屏幕像素；窗口不足用明确滚动条浏览，其他显示方式只能显式选择。 |
| 长提示挡住纤维 | 清空画布 tooltip，操作与状态留在固定控件中。 |
| 重入后窗口错乱 | 试验页面由嵌套 `QMainWindow` 改为普通 `QWidget`；同一入口重入不重新布置窗口。试验内隐藏主窗口底栏，反馈放在画面上方。SDK 仍指向隐藏但存活的旧预览 HWND，绝不改指试验窗口。SDK 控件启用 `WA_DontCreateNativeAncestors`，避免把整棵工作区提升为原生窗口。 |
| 标尺难发现、切页／重启后丢失 | 直接使用主程序的标尺库和 CU `.scl` 导入。固定显示已选名称和系数；按设备 ID、图像宽高保存明确选过的标尺，采集代次不参与键。不同设备／分辨率不会误用旧标尺。 |
| 切试验的数据归属不清 | 原代码已将历史保存在项目中，本轮没有把它误判为“历史被删”。现在固定显示试验类型、本场实测与累计实测；切换页面结束当前场并保留试验历史。 |
| 设置页拥挤、横向滚动 | 改为“试验准备／统计与汇总／报告／可选功能”四页，关闭横向滚动，长说明换行；滚轮不能改变下拉框、数值框。 |
| 上次直径在新场仍显著显示 | 换场清空最新直径显示；历史表继续保留原值。当前测径类别明确标在类别表头。 |

SDK 的实现不能只按手册推测：随包 `saa7130.dll` 的显示线程先调用渲染函数，再调用 AFTER 回调，并忽略该回调的 BOOL 返回值。关闭 `DISP_PRESENCE` 又会跳过这条处理链。因此保持 SDK 的原始目标 HWND 存活，在试验页真正隐藏它；回调返回值仅作为兼容遵守手册的 SDK 的补充。没有重置采集处理参数或重新打开设备。

## CU 含量试验（非冻结）的实际工作流程

### 试验前准备

1. 使用公共采集入口启动设备，选择适合当前光学倍率的已保存标尺。CU 的标尺也是共享且持久化的配置，不要求每个试验、每次启停都重新标定。
2. 准备样品、操作者、方向、类别；织物需要经纬重量。新软件沿用独立试验账本，原图保存默认关闭。
3. 默认实际像素显示。需要其它显示方式时，在尚未测过纤维的新视场中明确切换。

### 连续操作

| 用户动作 | 非冻结行为 |
|---|---|
| 类别按钮或画布右键菜单 | 选择测径类别；取消未完成草稿。右键菜单退出而未选项时不改类。 |
| 第一次左击 | 固定当时已经显示的像素及起点，主画面继续更新。 |
| 移动鼠标、第二次左击 | 绘制草稿；第二次点击使用本次事件坐标提交局部测径。失败明确提示，不自动转自由测量。 |
| 数字键／小键盘 1–9 | 默认给对应类别补计，不切换测径类别，不修改上一条直径。长按不重复计数。 |
| 单独按下并释放 Ctrl | 切换计数／NK；Ctrl+C、Ctrl+Z 等组合键不切换。NK 中数字键仅选类。 |
| 后选 | 只迁移本场当前有效操作对应的最新实测记录。取消、失败、换场后不能追改更早记录。 |
| 减号 | 仅减少补计，最低零；补计没有虚构的直径。 |
| 视场移动 | 取消草稿、在算请求与待确认项，清本场标记和列表，保留已入账历史。连续移动不反复新增空场，稳定后再接受测量。 |
| 更换操作者 | 结束当前场、切换该人的经纬／类别上下文，历史保留。 |
| 更换经纬方向 | 按 CU 约束，本场有实测／待处理测量时先提示使用“新视场”；不悄悄清掉正在复核的本场记录。 |
| 停止／重启采集 | 测量暂停，旧任务失效；同设备同尺寸自动恢复已选标尺。 |
| 切换含量／直径试验 | 分别保留项目内的试验历史，回到相同类型继续该试验；标尺属于设备，不属于临时页面。 |

测量入账、额外计数、当前场显示是三套不同状态。侧栏均径只来自实测直径，总根数包含补计；换场不清空试验账本。报告、历史复核和低频设置不参与逐根测量路径。撤销／重做继续使用真实操作历史，没有复制 CU 将“删除最新条目”称作“恢复”的歧义。

### CU 的四种显示方式

| CU 名称 | 原实现 | 本轮接入 |
|---|---|---|
| 实际像素显示 | 内部模式 0，出厂默认，比例 1 | 默认；不随窗口大小缩放；明确处理 Qt 高 DPI。 |
| 当前窗口显示 | 模式 1，保持纵横比适配 | 用户显式选择后适配，不自动替代实际像素模式。 |
| 指定比例显示 | 模式 3，输入百分比再除 100 | 显式百分比，只改变显示，不修改采集像素或测量系数。 |
| 指定倍率显示 | 模式 2，光学标尺结合屏幕标定 | 使用 500 屏幕像素标线的实测毫米长度，独立保存显示器配置。不是普通 2x／4x 像素缩放。 |

物理倍率换算：`图像 μm/px × 指定倍率 ÷ (屏幕 mm/px × 1000)`。CU6 对应命令 32813／32816／32824／32838；含量非冻结许可函数 `0x6a8980` 检查本场列表数量，非空则提示“请在新视场中更换显示模式”。CU5、免脱色版也有对应检查。

CU 的比例加减按钮另走入口，每次加减 5 个百分点，旧版漏过空场限制；本轮不复制该漏洞。原 CU 的静态代码只证明 Windows 客户区坐标比例 1，未证明高 DPI 下等于物理屏幕像素。新软件明确定义实际像素为物理 1:1，这属于新实现的显示契约，不能冒称原 CU 高 DPI 实测结论。
