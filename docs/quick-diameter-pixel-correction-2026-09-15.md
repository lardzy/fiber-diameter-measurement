# 快速测径扩展像素修复

日期：2026-09-15；测径自检修订号：`3`。

## 使用方式

在“设置 → 图像与智能分析 → 快速测径扩展像素”中输入数值并应用，然后生成新的快速测径结果。

- 数值表示**原图像素中，直径线每个端点的修正量**，范围沿用 `-20～20 px`，支持小数。
- 正值：两端沿直径线向外延长；负值：两端向内收缩；`0`：原始结果。
- 在未触及最短长度时，最终直径 = 原始直径 + 2 × 设置值。
- 过大的负值会保留最短 `2 px`，防止两个端点交错。

以本机实际测得的 49 px 原始直径为例：

| 设置值 | 修正后直径 |
| ---: | ---: |
| 0 px | 49 px |
| +2 px | 53 px |
| -2 px | 45 px |
| +3.5 px | 56 px |
| -3.5 px | 42 px |

结果见 [correction_results.json](research/quick-diameter-correction-2026-09-15/correction_results.json)。设置页同步增加了说明和悬停提示。

## 原因与修复

设置的保存和传递正常。原实现把正向延长限制在分割掩膜内，而自动测量的两个端点已经到达掩膜边界，因此正值几乎不生效。例如修复前，49 px 的结果设置 `+2` 或 `+3.5` 都只得到约 49.5 px。

现在对计算完成的直径线直接做几何修正，保持方向和中点，允许端点越过高亮边界。修正量在恢复到原图坐标后应用，因此不随内部计算图的缩放改变。

诊断信息保留原始直径 `uncorrected_diameter_px` 和实际总修正量 `diameter_correction_px`，便于核对最终结果。预览确认和提前确认后由后台写入的两条路径都使用同一实现。
