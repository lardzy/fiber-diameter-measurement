## 三批功能的落点

### 第一批：配准与采集位置

- `slide_registration.py`：只建立上下左右邻接；同一源文件／会话、相同焦层索引和相同 Z 命令坐标才提供配准证据。逐层独立估计，再检查共同 XY 位移；不同层的高可信结果冲突时拒绝共享平移模型。
- 入口先扣除定位不确定度，要求有效重叠至少 10% 且条带至少 64 个保存像素。默认定位余量 2%、搜索范围为视场主轴尺寸的 ±4%，有校准证据时扩大不确定度余量，不能借此扩大搜索框。上述均为保守工程参数，非通用测量标准。
- 相位相关给出多个受限候选，SIFT 提供相互匹配、比例检验、空间分布和仅平移共识。检查高通 NCC、分区支持、候选歧义、平行纤维的方向不确定性和二维周期纹理；两条候选路径冲突则拒绝。
- 已通过检查的位移用 `MOTION_TRANSLATION` 的 ECC 作小范围亚像素精化，不能引入旋转、缩放或投影变换。使用范围和运动类型遵循 [OpenCV ECC 接口](https://docs.opencv.org/4.13.0/dc/d6b/group__video__track.html)。
- 全局求解保留弱物理位置先验、按连通分量固定位置中心，并用稳健权重与有限次数的冲突连接移除避免累计矛盾。孤立视场保留名义位置。发布前再次验证最终实际接缝，每层单独记录结果；仅通过部分焦层就显示“仅部分焦层”。处理原则参考 [BigStitcher 的全局优化和不连通区域安排](https://imagej.net/plugins/bigstitcher/global-optimization)。
- `slide_capture_geometry.py` 与校准辅助：新“校准联动真实重叠”模式同时计算物理步距、保存像素步距和交叉方向位移。校准档案绑定相机、物镜配置、保存分辨率、轴方向和步距符号；有原始相机尺寸记录时，还核对原始分辨率。记录正反方向样本、重复性和方向差异。接受新的电机步距时不再混用旧像素间距。
- 原模式保持旧行为，并在设置中明确写明“名义重叠排布（不改变电机步距）”。启用校准联动时建议 20%，未取得有效 X/Y 校准不得自动改变电机步距。不能在未知物理映射时静默把旧设置改成 20%。
- 地图边界只决定行列数，绝不拉伸固定步距。预览尺寸考虑交叉轴偏移；采集前按冻结计划估算时间和容量，并比较原电机步距下的同范围计划。固定行列时明确说明图像数量不变、覆盖范围改变。
- Z 回差补偿仅使用用户实测值，默认 0 表示未校准；有有效值时每个视场先从较小 Z 方向接近，再依次采集焦层，保留停稳、新帧及软限位检查。设备没有编码器反馈，因此始终记录为电机命令坐标，不宣称验证了实际物理焦层。

### 第二批：独立修复视图与统一测量来源

入口为 **工具 → 数字切片工具 → 检查并修复拼接**，也可打开已有版本或暂停检查。后台完成后，有测量、草稿、待提交结果或拖动操作的工作区不自动切换；原版的测量和历史始终保持原版坐标。即使所有接缝都被拒绝，也能打开独立“拼接检查”视图：保留名义坐标、显示失败接缝并限制自动跨缝识别，避免退回未标记的原视图后丢失这些约束。

- `SlideLayoutSnapshot` 和逐层证据是不可变运行时记录。附属文件 `.fdmstitch` 原子写入；摘要绑定图像 BLOB、几何、焦层及相关采集信息，与文件名、修改时间无关。源文件改名仍可核对，同名替换原图必须拒绝旧布局。
- 独立修复文档复制类别和尺寸标定，重新生成类别及文档 ID，不复制旧测量几何。项目嵌入正在使用的布局；附属文件被删除后仍能恢复。含修复布局的项目使用 schema/min-reader 3 和必需功能 `slide-stitch-layout/v1`，旧读取器不能忽略布局；普通项目仍写 schema 2。
- `SlideRasterSource.read_region()` 统一选择每个像素的唯一来源：优先离视场边缘较远的图像，稳定排序处理相同距离。孔洞、四视场交汇、负坐标平移及缺失覆盖使用相同规则。按全局像素中心固定线性采样，不羽化混合，不按缩放或加载顺序切换归属。所有原始视场完整保留。
- 精确显示、魔棒、快速测径、边缘吸附和视口叠加图导出均经过修复布局的存储读取入口；浏览 LOD 使用同一像素来源规则，精确测量仍读取保存分辨率。原始单视场读取接口保留。原始解码缓存与布局合成缓存使用不同身份，旧布局结果不能覆盖新布局。
- 未验证接缝显示橙色虚线。分割覆盖掩膜去除未验证来源边界和缺失覆盖；跨缝结果显示不完整并阻止 F / Enter 确认。未触及接缝的对象继续使用原来的填孔功能。
- 手动线、折线、面积及孔洞按整个几何范围检查，计数点检查其位置；跨缝或缺失覆盖写入质量状态。记录固定布局、源摘要、焦层、采样方式。计数不宣称已自动去重。
- 常规 Excel 和模板导出增加“拼接质量说明”工作表，模板原有数据单元格不移动。视口叠加图增加质量说明，PNG 同时记录布局及对象来源元数据。

### 第三批：采集后台任务与网络边界

- 所有切片共享一个 `spawn` 计算进程，OpenCV 内部线程数限制为 1。仅传文件标识和小型进度消息，不向队列积压 Z 栈图像；待处理切片最多 32 个，同一个切片合并重复任务。
- 原图写入后，每四个完整视场调度一次证据预计算；完成任务取代同源的中间任务。正在写入的 SQLite 使用只读 WAL 访问，最终版使用一致读事务。计算按局部条带进行，不分配整幅切片大图。
- 断点保存图块内容摘要和算法版本，恢复时复用未变化的证据。算法验收规则改变后不能直接沿用旧候选。检查点批量写入；主动暂停时保存已完成证据，异常或强制结束保留上次原子检查点。同一切片暂停后，后续写图通知不会重新启动检查；手动继续或启动新采集时恢复。
- 原片发布与修复元数据发布使用独立流程。修复发布为单独进程，超过 30 秒结束该发布尝试并报告本机恢复位置；原切片成功不会因此变成失败。每个已完成布局保留不可变的本机版本，用户可重新检查以重试发布。
- 关闭软件先停止计算及发布，再释放切片与本机缓存。保持现有采集完成弹窗的 `reset()/hide()/deleteLater()` 顺序。

## 本机基准

脚本 `scripts/benchmark_slide_stitching.py`。单 OpenCV 线程，每种尺寸 5 个已知亚像素平移，最终运行未与测试套件并发；计时包含一对图像的候选搜索、质量检查及精化，不含图像生成。

| 保存图像边长 | 接受数 | 位移误差 P95 | 配准 P50 | 配准 P95 |
|---|---:|---:|---:|---:|
| 2K | 5/5 | 0.020 px | 1035 ms | 1047 ms |
| 4K | 5/5 | 0.023 px | 1764 ms | 1951 ms |
| 8K | 5/5 | 0.040 px | 2711 ms | 2901 ms |

这是随机纹理合成样本，不能代表纤维现场成功率，也不能把后台算法耗时当成输入响应延迟。早期只用相位相关精化时，2K/4K 的 P95 误差曾为 0.67/0.77 px；增加受限的仅平移 ECC 后达到上表结果。8K 压力脚本本身生成大尺寸真值场，脚本进程峰值不能直接当成配准条带的工作内存。

旧 2% 样本的本机副本共 900 张图像、180 条邻接接缝，全部因有效重叠不足拒绝，初次检查约 0.52 秒。该结果验证了门槛会在解码和候选搜索前拒绝明显不适用的样本。

复现命令：

```bash
QT_QPA_PLATFORM=offscreen PYTHONPATH=src .venv/bin/python -m pytest -q --tb=short
PYTHONPATH=src .venv/bin/python scripts/benchmark_slide_stitching.py \
  --output .tmp/stitch-implementation/final-benchmark.json \
  --slide .tmp/stitch-implementation/real-overlap-20.fdmslide
```

## 回归与验收边界

定向回归覆盖：已知整数／亚像素位移、低重叠拒绝、空白／平行纤维／二维周期纹理、不同 Z 坐标和层间矛盾、最终仅部分焦层通过、断点与算法版本失效、源文件移动／内容修改、单源合成顺序／ROI 一致性、DPR 1/1.25/1.5/2 的精确读取、整个几何质量标记、模板原单元格保持、独立视图和项目保存恢复、魔棒局部掩膜／填孔／确认、取消重启、无标准输出流进程、发布失败／超时、实测 Z 回差接近和软限位。

完整测试在同一进程中 **2812 项通过，1425 个子测试通过，耗时 334.52 秒**。结果保存在本机 `.tmp/stitch-implementation/full-regression-final.txt`。最后补齐“暂停后续写图仍保持暂停”边界后，配准、查看、采集、配置、生命周期及分割坐标的 **157 项定向回归通过（24.47 秒）**；日志为 `.tmp/stitch-implementation/final-focused-regression.txt`。编译检查和 `git diff --check` 通过。

未完成的外部验收：重新构建的 Windows 无控制台安装包、真实样品台／相机的回差和实际重叠标定、SMB 真断网、长时间连续采集，以及真实可配准同层地标的误差。当前样本不满足成功验收的真实重叠条件；不会将合成精度、离屏 Qt 测试或模拟网络失败称为真机验收。并不承诺所有纤维面积误差低于固定百分比。
