# 采集与试验设置及测量图片存档

版本：0.4.14。

在主界面“设置 → 采集与试验”调整含量试验和直径试验的显示与测量偏好。试验内的“高级设置…”打开同一页面；快捷控件也使用同一份偏好。设置全局共用，重启后保留。

## 显示与标记

- “显示视场稳定状态”默认关闭，控制底部两侧日常稳定提示。视场核验仍然运行，异常和未入账原因继续显示。
- 含量试验默认显示类别全称；直径试验默认显示直径值及单位。测量编号仍可在记录与悬停详情中查看。
- 白色背景默认关闭，可以调整内容、字体、字号、粗体、斜体和颜色。默认文字跟随测量线／类别颜色；选择自定义颜色可覆盖文字颜色。
- 字号按屏幕显示，缩放图像不会放大文字。候选、待确认和未入账状态不会被当作已完成的类别标记。

“应用／确定”更新当前及后台已打开的试验。“取消”丢弃未应用的设置草稿；恢复本页默认后仍需应用。设置预览使用与试验画布相同的文字绘制。

## 图片存档与清理

“保存测量图片”默认关闭。手动开启后，之后的含量与直径测量按此偏好保存图片；开关和格式跨重启记忆。支持局部 JPEG 和完整 PNG。局部图片按原始分辨率裁剪并使用 JPEG 有损压缩，有透明信息时使用 PNG。

设置变化影响之后开始的测量，正在处理的测量沿用开始时的图片策略。关闭存档不会删除已有图片，也不会回填先前未保存的图片。

图片先写入程序临时目录。**图片写入完成不等于项目已经保存。** 保存项目成功后，图片进入项目资源目录；仍供撤销、保存或复核使用的临时副本暂时保留，无引用后在后续清理中回收。

- 确认不保存并退出或切换项目：清理被放弃项目独占的临时图片。
- “结束并换样”成功：清理被移除试验独占的临时图片。
- 仅切换页面／保留的试验、取消退出、保存失败：保留仍需使用的图片。
- 异常退出：下一次启动在后台清理归属明确且已退出实例的临时图片。

退出不等待整轮维护扫描完成；尚未回收的临时图片在下次启动时继续清理。

设置页的“立即清理无用临时图片”只回收无引用的程序临时文件，不删除当前试验、项目资源、另存原图、Excel或报告。仍在写入、复核、撤销及保存使用中的图片会保留；其他运行实例和无法证明归属的旧目录会跳过。清理不要求关闭相机，失败项不阻断测量。

## 测量与分析

手势、交互模式、算法、候选显示等高级配置为应用偏好，不修改本场类别、重量、样品、测量结果或Excel输入。切换手势会取消尚未完成的取点；已经提交的测量保留原参数。算法改变后旧候选不能继续混用。

“分析当前视场”“取消分析”“光照检查”和空白参考采集仍是试验中的操作，不会因打开设置而自动执行。

空白参考采集成功后，参考引用自动保存到全局设置；平场开关保持原值，不自动启用或分析。即使主设置窗口已经打开，新参考也不会被尚未应用的显示设置覆盖。
