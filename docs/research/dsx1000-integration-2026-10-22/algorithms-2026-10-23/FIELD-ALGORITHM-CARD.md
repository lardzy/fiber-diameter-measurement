# 现场算法对照操作卡

本卡补充已有采集接口验证，不改变默认观察原则。先用已交付的收集工具记录原厂正常操作，再按既定受控验证流程检查硬件；这里的算法对照无需让研究原型连接设备。

## 带到现场与会话准备

使用 [收集工具目录](../collector/) 中的 Windows ZIP 与中文操作卡，先核对 SHA 和运行环境。算法 Python 源码供回到分析机重放，不要求在 Win10 1909 设备上安装依赖。收集目录与原厂输出目录分离。

先完成安装身份核对：DSX/CTRL/算法 DLL 版本和 SHA，实际启动模式，镜头及 NA、物镜倍率、光学变倍、像素标定、曝光、增益、白平衡、分辨率、位深/通道、快速/精细、Z 起止/间距/层数。参数保留原样，小数不要静默取整。

若相关 INI 在采集程序允许读取的目录中，复制当次有效配置，例如频带权重、NMV、拼接开关；不能只把程序自带默认值当作运行值。配置/日志可能含凭据，沿用收集工具的脱敏和不采完整命令行规则。

## 建议的数据组

| 数据组 | 原厂操作和保存 | 对照目的 |
|---|---|---|
| A：单位置五层 | 固定视野，使用原厂实际允许的小数 Z 参数，记录实际层数；保存每层原图、顺序、名义/实际 Z 及最终 EFI/高度结果 | 区分层距、首层原点、边界峰与高度量化 |
| B：真实业务 Z 栈 | 在有纹理、弱纹理、细纤维交叠或台阶的区域，各完成一次原厂多焦层采集；快速/精细分别建会话 | 区分算法模式；验证单值高度对交叠结构的限制 |
| C：3×3 图块 | 按已有45张模板逐项记录，保存未拼接 tile、每 tile 五层和 XY 先验；保存原厂拼接结果 | 配对位移、环路残差、连通性、接缝及跨层布局 |
| D：预览防抖 | 原厂正常移动与停止时记录预览、原始保存图和事件时间线；有条件保存连续原帧 | 区分显示偏移、实际像素、曝光模糊与稳定延迟 |
| E：可选反光抑制 | 同一原始图分别关闭/开启增强，保存参数和结果；可选含高光与暗部纹理场景 | 验证色调曲线、通道顺序、饱和区和尺寸限制 |

不要为获得模糊或失配样本去故意碰撞/振动设备；正常操作中已有的移动、弱纹理和重复结构即可提供反例。未能导出原始层时，记录原厂保存选项和实际产生的文件；不要把 EFI 成图复制多份当成 Z 栈。

## 每次实验的记录顺序

1. 新建实验身份，填写条件，记下所有参数来源（原厂 UI、文件、接口或人工）。先确定该次独立输出名称。
2. 开始观察并标记操作。记录原厂显示完成、文件变化、取消或异常；这些仍是各自来源的观察，不自动升级为硬件完成。
3. 原厂完成后核对文件数量、焦层顺序、实际命名和重复名称。记录原始 TIFF/专用格式及任何伴随标定文件，保留原格式。
4. 停止观察后复制所选原图、原厂输出与日志并校验。测量过程中不要对大图反复哈希。
5. 导出会话 ZIP，确认缺失项/权限失败/异常已列出。若图片涉及保密样品，按既有数据管理方式带回，不通过在线服务上传。

收集工具不会自动运行五层或45张扫描。需要控制时仍逐项使用已确认的接管、短距离移动、拍照及释放流程；停止记录与停止拍照是不同操作。

## 回来后的对照表

| 项目 | 记录量 | 判读约束 |
|---|---|---|
| 栈完整性 | 唯一 frame/acquisition ID、顺序、每层 Z、重复图哈希、缺层 | 重复哈希只是线索；静止图可能相同，缓存新鲜度还需采集身份 |
| EFI | 同原图重建的局部纹理、边缘、拼接/裁边变换；原厂与原型差图 | 先匹配位深、参数、颜色和几何，不能直接比较不同裁剪的图 |
| 高度 | 原始/滤后高度、边界峰比例、测得/补值/无支持比例；台阶或已知平面误差 | 没有标样只做相对比较，不给出绝对光学精度结论 |
| 配准 | 人工可辨地标误差、每边位移/分数、环路残差、连通分量、先验回退 | `q`、coverage mask 与配准可靠性分别记录 |
| 稳像 | 原始位移、显示位移、门控/重置、采集时间；平坦/重复区域反例 | 防抖状态不能替代运动到位或曝光结束 |
| 反光抑制 | 原图与增强图、饱和像素比例、暗部对比、通道变化 | 单图增强不会恢复已丢失信息；保留未经增强的定量输入 |
| 性能 | 运动、必要稳定、曝光/取帧、编码/写盘、重建分项时间与逐层 P50/P95 | 固定区域、层数、间距、分辨率/质量；无法等效条件单列 |

最有价值的带回材料是“同一完整原始输入 + 当次参数/版本 + 原厂结果 + 可核对的位置与时间”。只有截图或一张合成图，只能说明显示效果，不能完成复现对照。
