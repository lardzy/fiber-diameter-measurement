# 收集器无设备验证记录

日期：2026-10-22。范围为独立工具、模拟服务与合成文件；未启动原厂软件、连接真实 DSX 或修改 FDM。最终 EXE 身份见 [build-identity.json](validation/latest/build-identity.json)，逐项结果见 [self-tests.json](validation/latest/self-tests.json)。

## 环境与结果

- Windows 11 ARM64 虚拟机，系统版本10.0.26200；生成并运行 x64 WinForms 程序。验证进程未提升管理员权限。
- 现有 .NET Framework 编译器4.8.9221，C# 5；未安装开发环境。源码、目标属性及配置以 .NET Framework 4.8 为目标。
- **严格的4.8目标框架引用验证仍有缺口：虚拟机没有4.8 reference pack，使用现有4.8.1框架程序集编译。** 提供可运行的候选 EXE 与 PowerShell 基础盘点版；不把虚拟机成功等同于4.8/Windows 10 1909兼容性验收。
- 共35项核心收集与协议模拟测试（17项核心＋18项协议），逐项结果见 JSON。PowerShell 兜底在缺失安装目录时成功导出34项缺失身份和基础 ZIP，未主动连接端口。
- 实际 WinForms 窗口在1280×720、1366×768、192 DPI（200%缩放）下逐页渲染并检查顶部/底部，共12张截图。按钮文字完整，长页面可滚动；默认连接、移动和拍照均禁用。未实际覆盖100%/150%缩放及跨屏 DPI 切换。
