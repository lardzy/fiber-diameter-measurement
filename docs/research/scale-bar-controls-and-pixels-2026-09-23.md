# 比例尺入口、样式与像素精度

## 交互调整结论

将入口放在**右下角、对象捕捉左侧**，与对象捕捉和视图缩放组成紧凑的画布控制区。顶部工具栏保留文件、导出和测量操作。

采用带下拉菜单的按钮：主区始终打开／返回编辑，选中状态表示比例尺仍在显示；文字区分“关／显示／编辑”。菜单提供显示开关、编辑和定位。完成编辑后再点一次即可重开；隐藏右侧属性区后也能直接找回。面板顶部并排放置强调色“导出图片…”和“隐藏比例尺”，减少滚动查找。

这是结合本项目布局作出的设计选择，不是某款软件规定的按钮位置：

| 官方参考 | 可借鉴之处 | 本项目采用 |
|---|---|---|
| [QuPath 浏览界面](https://qupath.readthedocs.io/en/stable/docs/starting/first_steps.html#looking-around) | 比例尺伴随缩放变化，视图倍率可直接操作，线宽和字体可调整 | 将比例尺归入视图控制；常用样式放在画布旁 |
| [ImageJ Scale Bar](https://imagej.net/ij/docs/guide/146-30.html#sub:Scale-Bar...) | 明确区分物理长度、像素条高、字号，可用独立叠加层 | 长度、线宽／条高、字号分别设置，原图不变 |
| [Photoshop 管理比例尺](https://helpx.adobe.com/photoshop/desktop/use-grids-measurement-guides/measure-scale/manage-scale-markers.html) | 图形和文字可移动、编辑及隐藏 | 显示与编辑分离，返回编辑不先隐藏 |

常用区按显示范围、长度、位置、样式、线宽、字号、配色、预览范围组织。字体、粗体、文字上下位置和单独文字色收进“更多样式”。撤销／重做缩为图标，完成／取消放在同一行。测量、标注、水印仅在导出窗口选择；取消任何导出对话框或导出失败都保留编辑面板。

最近确认的配置在完成、隐藏或发起导出时保存；取消编辑恢复草稿前配置。新编辑会话默认导出当前图片；本次从综合导出返回调整时保留已有选择。新默认是红色、端点刻度、右下角，不覆盖用户明确保存的旧偏好。

## 科研规范与样式参考的边界

[Nature 图像规范](https://www.nature.com/nature/for-authors/formatting-guide) 要求使用比例尺与适当的 SI 单位。核查到的规范没有统一规定所有显微图片都必须采用某一种端点造型，不能将新增样式称为获得某种 ISO 认证。

[QGIS 官方比例尺文档](https://documentation.qgis.org/3.44/en/docs/user_manual/print_layout/layout_items/layout_scale_bar.html) 提供中、上、下刻度与分段样式。这是制图软件的成熟造型参考，不是显微图的强制标准。本项目选取适合水平图像比例尺的六种表现，全部使用同一物理长度计算。

| 样式 | 表现 | 长度定义 |
|---|---|---|
| 纯线 | 平端水平线 | 左右外边界间距 |
| 实心条 | 可调条高的实心矩形 | 左右外边界间距 |
| 端点刻度 | 两端向上、下伸出 | 端点左右外边界间距 |
| 上端点刻度 | 两端向上伸出 | 同上 |
| 下端点刻度 | 两端向下伸出 | 同上 |
| 四等分刻度 | 总长加 1/4、1/2、3/4 内部刻度 | 标签表示总长；内部刻度中心按总长的准确比例定位 |

## 像素实现

1. 原先端点使用居中描边，描边宽度会扩到标定区间外。改为向内的填充几何，左右外边界固定在标定长度上，短于线宽的尺条也不会向外扩张。
2. 依照 [Qt 坐标与栅格化说明](https://doc.qt.io/qt-6/coordsys.html)，使用浮点边界，避免 `QRect.right()` 的包含末像素语义；不把末像素索引误当作外边界。
3. 直接构造连续的上下边界，形成一个闭合轮廓后一次绘制，避免重叠带来的覆盖饱和，也避免浮点共边在 Qt 路径合并时丢失水平条。等分位置统一由总跨度计算，不逐段取整。
4. 普通图片、数字切片、画布及导出复用同一布局和几何。数字切片先转为局部原点，避免大坐标影响字体与边缘采样。
5. 字号、线宽和条高以原图像素定义；DPR 与缩放仅影响采样。未把亚像素长度取整后仍沿用原标签。

**可验证的精度范围：** 在整数对齐的原始分辨率测试中，100 px 跨度恰好占 100 列，线宽 1／2／3／4／5／8 px 均无端点额外列。非整数边界使用像素覆盖，测试覆盖 DPR 1／1.5／2 和不同缩放；Qt 的覆盖量有有限量化精度，测试容许不超过 1/32 像素的覆盖量差异，同时不允许出现区间外的完整像素列。这不意味着任意缩放下都能把每个边界落在整数像素上。

软件保证长度换算和几何的一致性；物理单位的准确性仍来自图片标定。验证数据、截图和 Windows 待验收范围见 [本轮验证记录](../validation/scale-overlay-2026-09-23/README.md)。
