# 专业二维测量与关联标注

本模块用于普通图像和数字切片的二维尺寸测量。可以手动取点，也可以引用已有辅助几何，或在原始像素上使用卡尺找边后拟合。结果、控制点、来源和标注布局随项目保存。

这里的尺寸精度取决于原图、标定、取点和边缘质量。拟合残差不等于实际计量精度；软件验证不继承 DSX 或其他显微镜的设备精度声明。本模块不测量高度、体积、粗糙度，也不提供完整 GD&T、标准圆度或直线度评定。

## 打开与基本操作

打开图像后，点击测量工具栏的 **专业测量**，或使用 **分析 → 专业测量**。该命令也可通过现有命令搜索找到。右侧显示专业测量面板，可在其顶部切换工具。

1. 先核对面板中的标定信息。已标定时显示 X/Y 方向的单位长度；未标定时长度为 `px`、面积为 `px²`，角度基于像素平面。
2. 选择工具。在“来源 1、来源 2……”中选择已有对象，或保留“在画布手动取点”。列表只提供与该来源类型相容的辅助点、线、圆、专业特征或现有直径线。
3. 点击 **开始取点**，按面板提示依次完成来源。固定点数的工具在点数满足后自动完成；折线、多边形、多点拟合需要点击 **完成 / Enter** 或在画布按 Enter。
4. 在专业结果表中复核各项指标。无效输入会显示原因，例如三点共线、零长度边、自交多边形或不平行的两条线，不会用有效的零值代替错误。

画布有键盘焦点时，Esc 取消尚未完成的取点、拟合预览或拖动。按住空格拖动或使用现有导航方式移动视图；切换工具会结束当前专业取点流程。更改工具来源或卡尺参数后，需要重新开始取点／找边。

来源列表中的对象引用与画布手动点选是两种不同输入：希望尺寸随某条辅助线更新时，应在来源列表中明确选择它。

## 可用工具与输入顺序

| 工具 | 输入与结果 |
|---|---|
| 两点距离 / X、Y 分量 | 取两个点，或引用一条线；输出距离、带符号的水平／垂直分量。 |
| 点到直线垂距 | 来源 1 为点，来源 2 为线；使用直线的延长方向。 |
| 点到线段最短距离 | 来源 1 为点，来源 2 为线段；垂足超出线段时使用最近端点。 |
| 平行线间距 | 引用或分别绘制两条线；不平行时报告无效。 |
| 沿基准方向投影 | 来源 1 提供待测两个点，来源 2 提供基准方向；输出带符号的投影长度。 |
| 三点角 | 按“第一点 → 顶点 → 第三点”取点；第二点是角的顶点。 |
| 两直线夹角 | 分别提供两条线；默认使用较小夹角。 |
| 三点圆 | 三个圆周点确定圆；输出直径、半径、圆心 X/Y。 |
| 圆弧 | 按“起点 → 经过点 → 终点”取点；输出经过中间点的圆弧长度、半径和圆心角。 |
| 两圆中心距 | 分别提供两个圆，测量圆心间距离。 |
| 两圆边界最短距离 | 测量非负的最近间隙；相交时为 0，包含关系下为两边界之间的最近间隙。 |
| 点到圆边界 | 先提供点，再提供圆；输出到圆周的最短距离。 |
| 折线长度 | 至少两个点，Enter 完成；累加相邻点之间的长度。 |
| 多边形面积 / 周长 | 至少三个点，Enter 完成；自动闭合并输出面积、周长。 |
| 相对坐标 | 依次提供目标点、原点、方向线，输出相对 X/Y。 |
| 手动多点拟合直线 | 至少两个点，Enter 完成；输出拟合线跨度，详情保留拟合质量。 |
| 手动多点拟合圆 | 至少三个点，Enter 完成；输出圆的尺寸和圆心，详情保留拟合质量。 |
| 直线卡尺 | 在目标边缘附近画一条基准线，沿多个垂直截面找边并拟合直线。 |
| 圆形卡尺 | 先点近似圆心，再点近似圆周；沿环状区域的径向找边并拟合圆。 |
| 双边卡尺 | 沿待测条带画基准线，各垂直截面搜索两条边；输出逐截面宽度、最小／最大／平均宽度、样本标准差及有效截面数。 |

三点角和两直线夹角可在开始取点前勾选 **使用补角（180° − 当前角）**，也可以右键已有角度标签，点击 **切换补角**。图上的角度弧表示实际采用的角域。

## 配合辅助几何建立基准

例如，需要以辅助点 O 为原点、辅助线 L 为 X 方向测量目标 P：

1. 在现有辅助几何工具中建立 O 和 L。
2. 在专业测量中选择 **相对坐标：目标 / 原点 / 方向**。
3. 来源 1 选择目标点，或在画布点选 P；来源 2 选择辅助点 O；来源 3 选择辅助线 L。
4. 点击“开始取点”。已经选择的来源会直接引用，剩余来源按提示取点。

X 正方向沿方向线的起点指向终点；Y 由与其垂直的方向确定。在常见图像坐标中，X 向右时 Y 向下。这是图像／标定平面中的相对坐标，不是样品台坐标。

修改关联辅助对象后，引用它的专业尺寸会重新计算。删除来源或使来源失效后，结果表会保留无效原因。需要停止随来源变化时，先选择结果，再点击 **解除关联并冻结**；只解除当前尺寸的来源关联，其他尺寸仍可继续引用原基准。冻结的是当前几何，之后改变标定仍会重算物理尺寸。

手动创建的专业几何在选中后显示控制点，可以拖动修改；关联对象应修改其辅助来源。卡尺结果通过“重新找边”更新。

## 卡尺找边与拟合

卡尺读取原始像素，数字切片的查看亮度／曝光不会改变找边输入。

**操作流程：**选择卡尺工具 → 设置搜索参数 → 点击“开始取点” → 画出基准线或圆心／半径 → 等待后台预览 → 检查搜索区、候选点和拟合图形 → 点击 **确认拟合并保存测量**。

直线与双边卡尺的两点决定沿边缘布置截面的位置和方向，搜索方向与该基准线垂直。双边卡尺应让搜索带包含被测条带的两侧边缘。圆形卡尺的界面使用完整圆周搜索。

| 参数 | 当前界面范围与含义 |
|---|---|
| 找边方式 | **梯度边缘**寻找灰度变化峰值；**阈值交点**寻找剖面局部灰度范围内的百分比交点并插值。 |
| 边缘极性 | 任意明暗、暗 → 明、明 → 暗；相对于当前搜索方向判断。 |
| 反向搜索 | 反转截面的搜索方向，应结合边缘极性检查结果。 |
| 搜索半宽 | 1～1024 px，默认 10 px；表示基准路径两侧的搜索距离，不是完整带宽。 |
| 采样截面 | 3～1024，默认 32；沿直线或圆周分布的搜索截面数。 |
| 采样间隔 | 0.125～4 px，默认 0.5 px；每条剖面内部的采样间距。 |
| 百分比阈值 | 0.1%～99.9%，默认 50%；用于阈值交点模式，相对该剖面的灰度范围，不是整幅图像的固定灰度值。 |
| 最小对比 | 0%～100%，默认 1.57%；对比不足的剖面不能提供有效边缘。 |
| 最低有效比例 | 1%～100%，默认 50%；限制成功提取并通过筛选的截面比例。 |
| 稳健剔除异常点 | 默认开启；降低离群边缘或异常截面对拟合的影响。 |

预览中的蓝色搜索区标明实际取样位置，绿色候选表示采用的边缘，红色表示未采用或被剔除的候选。面板以中文摘要显示有效截面数、采用／剔除点数、残差、圆周覆盖范围和失败原因；完整来源与质量数据仍保存在项目和导出明细中。不能只凭拟合曲线看起来平滑就认定测量准确。

失败时不会自动改为手动测量，也不会启用“确认拟合并保存测量”。可以修改参数后重新开始，或明确改用手动多点拟合。拟合过程中可按 Esc 取消；图像、焦层、标定或参数变化会使旧任务或预览失效。

已保存的卡尺结果可在表中选中，再点击 **重新找边**。它使用保存的搜索区域和当前面板参数，仍需检查预览并确认，才替换原测量。

## 阅读和调整标注

专业结果以 `P1、P2……` 编号；新增的现有直径、折线或面积标签以 `M1、M2……` 编号。尺寸线／角度弧说明测量位置。单引出样式通过虚线关联标签；双端引出样式通过尺寸界线、尺寸线和成对箭头表示测量的两个端点。

- 直接拖动标签可移动文字和引出线，不改变取点、测量值或数值明细。位置以相对于测量锚点的图像坐标偏移保存，缩放和平移视图不会重排手动位置。
- 拖动松开后记入撤销；拖动期间按 Esc 恢复原位置。拖动几何控制点则会改变几何并重算尺寸。
- 右键专业标签，可使用 **恢复自动位置**、**显示 / 隐藏引出线**、**标注属性：显示 / 隐藏编号**。
- 在 **标注属性：显示指标** 中，可选择该测量已有的指标。例如圆可显示直径、半径或圆心坐标，两点距离可显示水平／垂直分量。切换标签指标不删除结果表中的其他指标；适用的尺寸见证线也会同步变化。
- 现有直径标签的右键 **标注属性…** 提供引出线和编号选项。旧项目没有布局字段时保持旧显示；拖动旧标签或执行“整理标注”后启用关联布局。
- **整理标注**会重新安排当前文档的专业标签及现有测量标签，原来的手动位置会被替换；已选择的显示指标、编号和引出线设置保留。仅希望重置一个标签时，使用它的右键“恢复自动位置”。

专业标签、几何和结果表支持选中／悬停联动。画布已有的“全部标签／仅选中标签／隐藏标签”同样控制专业标签的屏幕显示。界面选择高亮不会进入叠加图导出。

### 连续线段的双端引出样式

新建的直径线和有唯一首尾的专业线性尺寸默认使用双端引出。现有直径标签可在右键 **引出样式** 中切换 **单引出** 和 **双端引出（尺寸线）**；专业标签在右键 **标注样式** 中切换。沿同一直线连续测量多个首尾相接的区间时，双端引出可以从静态图直接追溯每个标签对应的两端，无需靠悬停才能识别。

双端样式参照专业制图的对齐尺寸表达：两条细实线尺寸界线分别从实际测量端点附近沿法向引出，连接与被测线平行的尺寸线，并用成对箭头标出区间。端点保留小圆点；尺寸界线与端点留出小间隙，并略微超出尺寸线。此表达参考 [QCAD 对齐尺寸说明](https://www.qcad.org/doc/qcad/latest/reference/en/scripts/Draw/Dimension/DimAligned/doc/DimAligned_en.html)，只决定显示几何，不改变标定或测量数值。

拖动文字时，实际测量端点不动。文字移到测量区间外侧，会增加短连接线；文字遮住尺寸线端部时，尺寸线移到文字外沿，使两个端点投影仍可辨认。线段短到容不下成对箭头时，箭头移到外侧，同时保留区间内的尺寸线。这些选择参考 [AutoCAD 的尺寸文字与箭头适配说明](https://help.autodesk.com/cloudhelp/2021/ENU/AutoCAD-Core/files/GUID-E2E21B42-82AF-4D46-B9DD-F0844D20F719.htm)。FDM 使用明确的固定规则，不宣称完整实现 CAD 尺寸标准或全部排版选项。

切换样式只修改标注布局，支持项目保存和撤销。旧项目缺少样式字段时继续使用单引出；缺少关联布局时继续保留原显示。当前现有测量的双端样式适用于有唯一首尾的直径线，折线和面积继续使用单引出。普通图像、数字切片和叠加图导出共用同一尺寸布局。

## 结果、保存和导出

专业结果表按指标逐行显示，一项圆测量可能有直径、半径和两个圆心坐标行。选择任意一行可查看来源、标定、参数、质量及无效原因。数字切片中选择结果表的行会切回该结果的来源焦层。

**导出明细**可保存当前图像／切片文档的 CSV 或 Excel（`.xlsx`），包含所有专业测量的指标、测量 ID、图像 ID、焦层、状态、原因、来源特征、标定、参数和质量。无效结果保留状态与原因，数值留空。数字切片的焦层字段使用内部索引，从 0 开始。

专业测量不计入原有纤维直径均值、分类统计和业务模板。要获得专业结果，应使用专业面板的“导出明细”；现有直径数据继续走原来的导出路径。

勾选测量叠加图的图像导出会绘制专业尺寸与关联标签，保留用户指定的标签偏移。屏幕隐藏标签只影响查看，不等于删除导出标签。比例尺导出预览会提示超出导出范围的手动标签，不会偷偷将其移回画面。

几何、来源和标签布局保存到项目并参与撤销／重做；仅拖动标签也会使项目需要保存。标签调整不会改写原始像素或重新提取边缘。数字切片的查看亮度／曝光与原始导出边界保持独立。

## 数字切片与标定边界

- 专业测量绑定来源焦层，默认只在该层绘制；一个尺寸不能混合不同焦层的特征。切层取消未完成的取点和标签拖动。
- 需要在可测量视场中取点。卡尺的整个搜索区都必须位于已加载、完整覆盖的原生像素区域内；端点已加载并不代表中间缺失的瓦片可以参与找边。
- 普通图像和切片的卡尺搜索区都有大小检查；超过 128 MiB 或空区域会拒绝提取。缩小搜索范围、移动原生视场后再执行。
- 专业计算分别使用 X/Y 标定。非等方像素下，物理圆在图像上可能呈椭圆；已有辅助“像素圆”不能直接解释成唯一的物理半径，需要基于原始边缘点重新拟合。
- 改变标定后，根据保存的控制点重算。卡尺原始提取证据与当前标定下的重新拟合结果分别保留，重新评估可能使结果失效。
- 新专业特征保留可用的图像／切片来源身份；来源身份仍在核对或无法核对时，应等待或按提示处理。当已保存的来源版本与当前版本不符时，旧特征会失效，需要在当前来源重新取点或拟合。变更图像来源后应重新复核，不把旧结果直接视为新图的测量。

## 项目兼容与验证记录

含专业几何／尺寸的项目记录必需功能 `professional-measurements/v1`；含现有测量新标签布局的项目记录 `measurement-annotations/v1`；只要任一现有或专业测量使用双端引出，还会记录 `measurement-dual-dimensions/v1`。支持必需功能检查的读取器遇到不认识的标记时，会进入受限兼容状态并阻止覆盖原项目，避免无声丢失新字段。继续编辑时应使用支持这些功能的版本。

软件与合成数据验证结果见 [专业测量验证记录](validation/professional-measurement-20261027/report.md)。真实样品的尺寸准确度仍需使用已知尺寸样本、实际倍率和标定条件单独验证。
