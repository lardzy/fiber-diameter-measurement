# 数字切片设置：参数联动与校准提示

本轮基于拼接功能提交 `1e5b16f`，随 `0.4.6b1` 测试版交付。调整设置页的组织与反馈，保留既有配置字段、采集时序、物理参数默认值及配准验收阈值。

## 设置页行为

- 新增“拼接与采集步距”区域，集中展示模式、重叠率、XY 校准、预计步距及后台检查开关。
- 名义模式显示“排布重叠”，明确不改变电机步距；手动模式只显示相关输入；校准联动显示计算结果，保留原手动数值作为切回原模式时的配置。
- 校准状态区分 X/Y 缺失证据、配置/相机/方向/保存尺寸变化和原始相机尺寸变化。当前相机帧与历史档案估算分别标明；没有尺寸证据时不猜测视场大小。该说明只用内存中的设置与帧尺寸，不打开文件、不访问局域网或控制硬件。
- 设置页和采集计划共用保存尺寸计算，预计电机步距使用实际的联动计算函数。显示预计重叠及扣除定位余量后的结果；不足 10% 或 64 px 时就地说明，提高重叠时提示同范围大网格的近似数量增量。
- XY 采集步距校准与画布 μm/px 尺寸标定明确区分。Z 回差为 0 时显示“未启用补偿”，焦层间距明确使用电机命令步数。
- 区分手动移动、采集电机步距和图像排布间距；显示 XY/Z 各自的等待总和，保留两阶段等待。原始布局融合和本机磁盘缓存的适用范围写入页面说明。
- PNG 模式隐藏 JPEG 质量输入，切回 JPEG 保留原值；数值标签正常占用布局宽度，不再被滑杆挤出父控件。
- 保留非预设的采集/预览宽度，支持配置切换和导入后的往返保存。长配置名称限制控件宽度，完整已保存名称可在提示中查看。
- 恢复默认值只作用于当前采集配置；同时清除其不再适用的校准档案。采集锁定期间不能通过恢复默认值绕过参数锁定。

## 页面内的推荐起点

| 项目 | 建议 |
|---|---|
| 真实重叠 | 有效 XY 校准后从 20% 开始；不自动迁移旧配置的重叠率 |
| XY 等待 | 200 + 100 ms，按设备实测调整 |
| Z 等待 | 80 + 40 ms，按设备实测调整 |
| 丢弃帧 / 首张额外等待 | 2 帧 / 3000 ms；保留新帧检查 |
| 电机步距、焦层间隔、Z 回差 | 使用设备校准或实测值，没有通用 steps 推荐 |
| 预览 | 1280 px；与永久保存尺寸分别设置 |
| 保存图像 | 测量优先 PNG；JPEG 95 可作为容量优化的对照候选，需验证测量结果 |
| 保存分辨率 | 以原始尺寸为参考验证；修改后核对采集步距校准 |
| 磁盘渲染缓存 | 默认 2 GiB，多片反复浏览且 SSD 空间充足时可试 4–8 GiB |
| 原始布局融合宽度 | 建议 0 px；修复测量视图不使用此参数 |
