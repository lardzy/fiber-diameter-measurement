# Olympus DSX / POIR / MPOIR 设备文件

通过“打开图片”、拖放或“打开文件夹”选择设备文件。程序先在后台读取点位与通道清单，再按选择解码像素。文件原件不会被修改。

## 通道与点位

- OLS 默认勾选激光强度，可同时选择彩图；成功导入后记住 OLS 的常用通道选择。DSX 没有强度时默认选择彩图。
- MPOIR 按内部布局显示独立点位。点位下的通道可分别勾选，支持对已选点位应用通道设置；不会自动拼接点位。
- 每个所选通道成为独立图片，名字包含文件、点位和通道。测量、撤销、显示调整分别保存。
- “全选常用通道”只选择彩图与强度。高度位于默认折叠的高级区域，每次默认不选，收起高级区域会取消高度勾选。
- 同一来源、点位、通道再次打开时定位已有图片。“图像 → 同源通道…”可补取其他通道。
- 扫描取消不增加图片；导入中取消保留已完整完成的图片。损坏文件和不支持的结构会给出具体失败信息。

“图像信息与属性”可查看原始位深、设备、通道、来源路径以及当前双轴标尺。仅读取清单或标尺不会解码图像；ZIP 解压和文件指纹检查仍可能读取整个文件。

## 高度图

先展开“高级：高度图”，选中一行，再使用“预览高度”或“导出原始高度”。这两个动作不增加项目图片或分析任务。导出结果为原始计数 TIFF 和同名 JSON，JSON 保留 XY、Z 比例、单位、来源与校正依据。

确实需要保存高度图片时，勾选高度并点击“加入项目”。高度保留独立语义、原始 16 位值及显示映射，普通图像处理、自动纤维分割和批量分析不会把它当作强度图处理。可进行二维手动测量及显示/原始导出。

OLS 使用文件内置显示 LUT；DSX 高度采用灰度预览。高度原点、INVALID 辅助层含义及厂商粗糙度计算尚未建立完整对应关系，因此高度预览和 Z 比例不代表完整三维计量兼容。

## 标定

设备导入自动应用已验证的内置标尺：DSX 使用对应图层的 pm/px 字段；OLS 使用主图 µm/px 字段乘工厂 XY 校正系数。不会使用普通 TIFF 的打印 DPI 作为显微标尺，也不会取参考相机图的比例。

X、Y 像素尺寸独立参与计算：

- 线段长度为 `hypot(dx × sx, dy × sy)`；折线逐段求和。
- 面积为 `像素面积 × sx × sy`，包含孔洞的面积沿用同一换算。
- 水平标尺使用 X 比例，实际宽、高分别使用 X、Y；测量表、统计和导出使用相同结果。
- 裁切、平移、翻转保留比例；90°旋转交换 X/Y；缩放分别更新两轴。
- 非等方图片任意角度旋转超出正交双轴模型，需要明确清除派生标定后继续，或取消。辅助构图的距离参数与前后轮廓对比在非等方情况下使用 px。

“标定 → 从设备文件读取标尺…”也可仅查看、复制或应用标尺。选择来源点位与通道后，必须核对来源和当前图片尺寸，并确认是同一未裁切、未缩放的完整视野。尺寸不符或标定待核验时不能直接应用；应用可撤销。

非默认 OLS 用户校正、非默认 DSX 公共校正及无效/缺失比例，显示“标定待核验”，只按像素显示，不能自动继承项目默认标尺。后续明确进行人工标定或应用预设即可使用物理单位。双轴预设可分别设置 X 与 Y。

## 保存与旧项目

只保存已选通道的无损资源到项目 `.assets/imports/`，同时保存位深、XY 标定、显示映射、通道身份和来源证据。原始 16 位样本不会被预览图替代，显示变化也不改变原始样本。

项目保存后，已导入图片不依赖设备原文件。以后补取高度等未导入通道时，需要原设备文件；文件被移动后可重新定位，程序会校验指纹。不会仅凭同名文件替换来源。

本功能将项目格式升级至 v3。新版支持旧项目及旧单轴标定（视为 X=Y），升级覆盖保存前保留备份。旧版拒绝 v3；双轴侧车使用独立结构，旧版无法把它静默当成单轴标尺。移动项目时仍需同时保留 `.fdmproj` 和配套 `.assets`。

## 已验证范围

DSX1000 单张/拼接、OLS5000 POIR 单张/拼接及 MPOIR 五点位样张共 5 个容器、9 个数据集。默认导入 9 张常用图片、0 张高度；全选常用通道得到 16 张图片。25 个可选通道的原始像素已与前期独立读取器交叉验证的提取结果逐一核对。

OLS 单张中 100 px 横线和竖线分别为 12.6124217369 µm、12.6293839717 µm，与内置双轴工厂校正一致。已用强非等方合成数据验证斜线、折线、面积、变换、侧车、预设、撤销和保存恢复。

当前支持已验证的单帧二维布局；分块 OIR、真正的 Z/T 堆栈、未验证的 MPOIR 拼接布局及不同像素结构会明确报错。无须厂商 SDK，也未增加 `oirfile` 运行依赖。Windows 安装包及其他设备软件版本仍需在相应环境和样本上验证。

相关实现入口为 `services/device_image_io.py`、`ui/device_import_dialog.py` 及 `Calibration` 双轴模型。可用以下命令复核功能：

```sh
QT_QPA_PLATFORM=offscreen uv run --no-sync pytest -q \
  tests/test_device_image_import.py tests/test_main_window_image_processing.py \
  tests/test_image_processing_workbench.py tests/test_workbench_workflows.py \
  tests/test_main_window_analysis_integration.py tests/test_history_and_sidecar.py \
  tests/test_project_analysis_persistence.py tests/test_project_export_controllers.py \
  tests/test_models_project_io.py tests/test_display_adjustment_dialog.py tests/test_length_units.py
```

真实样张测试在本地样本目录不存在时会跳过；合成 DSX/POIR/MPOIR、通道选择、取消、持久化和双轴计算测试可独立运行。格式研究和原始校验依据见 [结构分析报告](research/olympus-formats-2026-09-21/README.md)。

## 后续处理：7 项既有回归失败（2026-09-21）

- JSON 检查：轮廓对比导出、基准脚本和 Windows 自检报告中的 7 处序列化调用补齐 `allow_nan=False`。增加 NaN、正负无穷回归，确认 Excel 导出失败时保留原文件。
- 5 项画布检查：根因在直接绘制路径。QWidget 的可见范围是逻辑像素，原代码又通过含设备像素比（DPR）的变换求逆，高 DPI 下错误缩小范围，跳过右侧及下方标签。改为在逻辑坐标中处理窗口和世界变换；QImage 保留物理像素换算。原有直接绘制／缓存绘制的像素误差阈值未放宽。
- 低缩放文字检查：旧断言早于“图像像素／屏幕自适应”字号语义更新。新建 8 px 文字在 1% 缩放时仍应保存 8，而非 800。修正测试并增加显式“按当前外观转换”为 800、撤销、视野导出和数字切片多焦层导出的覆盖；产品字号语义未改变。

新增的绘制可见范围检查覆盖 DPR 1／1.25／1.5／2、截图目标与屏幕不同 DPR、平移、旋转、非等比缩放、自定义 window/viewport、显式裁剪及无视口的 QPicture。

最终执行 `QT_QPA_PLATFORM=offscreen uv run --no-sync pytest -q --tb=short`：**3267 项测试、1573 个子测试通过，0 失败**，用时 390.12 秒。仅有一条既有 openpyxl 默认样式警告。`git diff --check` 通过；本记录为 macOS 本地源码回归，不代表 Windows 安装包验收。
