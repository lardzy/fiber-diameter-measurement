# 在画布上调整比例尺

## 使用流程

1. 打开图片，点击右下角“对象捕捉”旁的 **比例尺**。主画布立即显示比例尺，右侧展开编辑面板。按钮文字区始终用于打开或返回编辑，箭头菜单提供显示开关和定位。
2. 自动长度从 `1、2、5 × 10ⁿ` 中选择接近目标宽度 20% 的值。需要固定物理长度时切换到“自定义”，或者拖动右端控制柄。
3. 在图上拖动整个比例尺改变位置，或使用四角定位。样式、实际线宽／条高、字号和配色直接展示；字体、粗体和文字上下位置放在“更多样式”。
4. 点击面板顶部 **导出图片…**，在导出窗口统一选择测量、标注、水印、范围与文件格式，再选择保存位置。显示范围默认为全部图片，导出范围默认当前图片。取消导出或保存失败后仍保留编辑面板。

“完成编辑”收起面板并保留显示，此时测量、魔棒和普通选择照常使用。再次点击右下角按钮或“视图 → 编辑比例尺…”即可调整；面板顶部“隐藏比例尺”或下拉菜单中的“显示比例尺”开关可关闭显示。

首次使用默认为**红色、端点刻度、右下角**。已保存的用户偏好优先于新默认值。

## 样式与长度基准

提供纯线、实心条、端点刻度、上端点刻度、下端点刻度和四等分刻度六种样式，列表附示意图。

标签表示尺条**左右外边界之间的总长度**。端点向内绘制，改变线宽不会加长尺条；四等分刻度从同一总长度计算 1/4、1/2、3/4 位置。实心条的输入框显示实际条高。

整数边界、整数跨度可按原始分辨率逐像素核对。非整数长度或缩放保留亚像素位置，通过边缘覆盖表达；不能把抗锯齿后的非零颜色像素个数直接当作物理长度。不同样式的设计依据和精度约定见 [调研与实现说明](research/scale-bar-controls-and-pixels-2026-09-23.md)。

## 显示、位置和单位

- 显示范围可选“全部图片／仅当前图片”。全部模式也覆盖本次会话后续打开的图片。仅当前模式固定在选择该模式时的图片。
- 普通图片可预览整图或当前视窗；“定位比例尺 / 适合预览范围”用于重新找到比例尺。
- 支持 nm、μm、mm、cm、m，修改单位保持固定物理长度。不同标定的图片分别换算尺条像素长度。
- 未标定时自动显示 px，并提供“去标定”。已有固定物理长度不能当作像素长度使用。
- 自动字号按目标范围短边约 1.5% 计算，最低 12 个原图像素；精确字号不会再被原分辨率导出的 12–28 px 限制截断。
- 拖动约束包含整条比例尺和文字。固定长度或字号过大时会提示修正，导出预检会列出所有不符合条件的图片。
- 预览只是前景叠加，不改变原始图像、测量坐标、分割输入或项目文件。

## 配置记忆与撤销

- 编辑态有独立的“撤销调整／重做”，不会占用测量历史或产生项目未保存状态。
- **完成编辑、隐藏比例尺或发起导出**会记住最近确认的参数，不要求导出成功。取消导出不撤销已经确认的参数。
- “取消编辑”恢复进入编辑前（或本轮最近确认时）的参数；未确认的草稿不写入偏好。仍处于编辑态时直接退出，也不会保存未确认草稿。
- 下次启动软件时比例尺默认隐藏；再次开启会读取最近确认的配置。
- 所有图片共享配置，位置保存为角落或相对位置。旧设置和旧项目中的手动锚点可作为第一次编辑的初值，新操作不写入旧锚点。

原设置页中的重复比例尺表单已替换为“在画布编辑比例尺…”入口，文字和图形标注默认样式继续保留。原“导出比例尺图”和“导出测量 + 比例尺叠加图”进入同一个画布编辑流程。综合导出窗口的“在画布调整比例尺…”保留已选择的输出项目。

## 数字切片

数字切片以当前焦层的**原始像素视窗**为导出范围。画布框线持续标示范围；尚未获得匹配原点和焦层的原始像素时，框内显示等待画面，不把保留的旧焦层显示为当前导出预览。

导出开始前冻结焦层、视窗原点、尺寸、标定和比例尺布局。随后切图、平移、切焦或更改参数均不会修改正在导出的比例尺。整张数字切片及屏显整图导出限制保持不变。

## 验证与打包

开发验证、性能数据和截图见 [本轮验证记录](validation/scale-overlay-2026-09-23/README.md) 和 [初版验证记录](validation/scale-overlay-2026-09-22/README.md)。Windows 自检新增必过项：

`functional_checks.overlay_renderer.scale_overlay`

检查内容包含五种单位、DPR 1／1.5／2 的原点变换、字体大小、端点像素、亚像素覆盖、六种样式、等分刻度、未标定 px 和超长拒绝。Windows onedir 构建检查该结果及完整子项，缺失或失败会阻止构建自检通过。

macOS 开发验证不替代 Windows 安装后验收。Windows 还需实际核对中文字体、不同缩放的显示、数字切片焦层与视窗导出，以及安装后的设置记忆。
