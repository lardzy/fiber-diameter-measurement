# 数字切片计数、缩放和全屏快捷键修复

本次针对 Windows 0.4.5 安装包的反馈：局域网数字切片、60 多个计数对象、Ctrl＋滚轮缩放后编号异常变大，随后窗口持续无响应；全屏时小键盘切类别和撤销等快捷键失效。版本号保持 0.4.5。

## 已确认的原因与修复

### 1. 图像解码与界面绘制之间的死锁

用用户提供的切片样本在 macOS / PySide6 6.10.2 中复现了持续无响应，并取得 Python 线程栈及 macOS `sample` 原生线程栈。两条等待链为：

- 界面线程：`QDockWidget::paintEvent → QIcon::addFile → QImageReader → QBasicMutex::lockInternal`。
- 切片解码线程：`QImageReader::read → QBufferWrapper::isSequential → PyGILState_Ensure`。

后台 `QImageReader.read()` 虽然释放 Python GIL，但其输入是 Python 创建的 `QBuffer`。Qt 在持有图像插件锁时调用设备虚方法，会经过 PySide 包装层重新请求 GIL。此时界面线程持有 GIL、等待同一 Qt 锁，两个线程就无法继续。其它 Python 工作线程也会一起停住。

修复改用 `QDataStream` 在 C++ 内部创建的原生内存设备；原图解码和缩放层级解码共用这一入口，避免设备虚方法回调 Python。仍使用原来的 Qt 解码器、分辨率、色彩和方向规则。读取期间同时保留字节数组、数据流及设备的生命周期。该构造方式由 [Qt QDataStream 文档](https://doc.qt.io/qt-6/qdatastream.html#QDataStream-3)明确支持。

并发对照使用两个后台解码线程及一个界面图像加载线程，各执行 600 次。只替换解码函数，旧函数取自本次修改前的 Git HEAD：

| 路径 | 三次独立进程结果 |
| --- | --- |
| 旧 Python QBuffer 输入 | 全部超过 4 秒限制，被测试驱动终止 |
| 新原生 Qt 内存输入 | 全部正常完成，约 0.15～0.18 秒（含进程启动） |

这些耗时用于证明并发任务能否完成，不是图片加载或画布帧率的性能指标。已将有超时保护的并发用例纳入回归测试；同时检查完整及缩放解码设备确实由 C++ 创建。

**边界：本机已复现并修复这一真实死锁，但尚未取得用户 Windows 进程的线程转储，不能断言其持续无响应只有这一个原因。**

### 2. 64 个计数对象进入缓存后，编号随整张切片放大

仅有点和线的文档达到 64 个对象后，会进入叠加缓存。原整图预览最大边为 1536 像素，但计数标记和字号仍按屏幕尺寸绘制。放大整张切片预览时，这些内容也一起被放大。

数字切片现在将计数标记和编号从整图预览中分离：过渡时按当前视口和倍率直接绘制可见计数，复用文字精灵及空间索引；精确图块就绪后继续使用图块缓存。保持全图编号、类别颜色、选中反馈和计数最后绘制的顺序。面积等复杂轮廓仍走原缓存路径。

此外，将整图预览的原生 `drawImage` 目标和对应源区域裁到当前视口，避免把几十万像素宽的目标矩形直接交给 Qt。此项用于限制显示工作范围，并不是上述死锁的根因修复。

### 3. 精确叠加图块不再等待底图 I/O

原实现把未完成的切片读取、概览预取也视作导航未结束，阻止精确测量图块启动。现仅在实际拖动、方向键平滑移动时推迟过时图块；底图读取待完成时，测量几何可以独立准备。底图版本仍独立校验，未放宽像素测量的可用条件。

### 4. 快速图块完成造成队列重入与状态残留

缓存请求会主动处理已完成消息。空图块或简单图块完成很快时，完成通知可能先于“当前任务”的赋值；原完成回调又立即启动下一块，导致一次回调递归处理整批图块，并残留已经完成的活动任务。

现先登记任务，再提交请求；下一块通过绑定画布生命周期的 Qt 定时回调启动，完成后让出事件循环。快速完成测试在修复前复现一次递归启动 6 块，修复后每次回调只启动一块、最终没有残留任务。

### 5. 全屏快捷键

- 小键盘数字包含 `KeypadModifier`，类别快捷键现忽略该设备标志，仍保留 Ctrl、Alt、Shift 规则。
- 原窗口命令只关联菜单和工具栏，全屏隐藏它们后快捷键会失活。现也关联到主窗口，继续采用 `WindowShortcut`，不扩大为全局快捷键。
- 实际 Qt 按键回归覆盖普通图片及数字切片的主键盘、小键盘、Ctrl＋Z、Ctrl＋Shift＋Z 和吸附切换；文本框内数字输入、撤销仍由文本框处理。

- 解码：PNG/JPEG、8/16 位灰度及 RGB/RGBA、色彩信息、图像元数据、EXIF 方向、错误格式回退及无效数据；并发解码与界面图片加载。
- 用户样本 `/Volumes/LARD/2.中转/2601967138A.fdmslide` 仅以只读方式访问。使用主窗口及真实 Qt 按键/鼠标事件，完成 240 轮 Ctrl＋滚轮、右键拖动、切类别和点击；60 个初始计数增至 83 个，越过 64 个缓存阈值。大范围浏览或原生像素未就绪时，点击继续按原规则不接受。
