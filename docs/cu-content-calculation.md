# 实时含量试验：计算规则与 CU 对照

本文说明当前 `cu-content-rules-1` 的实际计算，依据是恢复的 CU“含量实验－非冻结”模块、Excel 模板／VBA，以及本项目的 [statistics.py](../src/fdm/live_experiment/statistics.py) 和 [models.py](../src/fdm/live_experiment/models.py)。对象为 `CMsgAdmin2`，不混用普通非冻结测径的 `CMsgAdmin4`。

11 个方法名称沿用原软件标签。这里描述的是已恢复的软件规则，**不表示对这些标准全文、现行版本或物理计量符合性完成认证**；统计快照明确保存 `standards_compliance_verified=false`。操作说明见 [实时试验](cu-live-measurement.md)，有意修正及未验收项见 [CU 差异清单](validation/cu-live-measurement-2026-10-15/CU_DIFFERENCES.md)。

## 1. 输入、统计数据域与补计数

对一个操作者、一个方向、一个材料类别，记：

| 符号 | 含义 |
|---|---|
| `d_j` | 第 `j` 条已入账的原始直径，单位 μm，正有限数 |
| `m` | 实测条数 |
| `c` | 额外计数；独立计数事件，不构造直径 |
| `N=m+c` | 参与含量权重的总根数 |
| `ρ` | 试验材料快照中的正密度 |
| `h` | 组距，单位 μm |
| `x_j` | 本次计算使用的直径值：原始 `d_j` 或其组中值 |
| `μ` | `Σx_j/m` |
| `q` | `Σx_j²/m`，即“平方的平均”，不是“平均的平方” |
| `s²` | `Σ(x_j−μ)²/(m−1)`，样本方差 |

分组区间左闭右开，`k=floor(d_j/h)`，区间为 `[kh,(k+1)h)`，计算使用 `x_j=(k+0.5)h`。分组均值、平方均值和方差都按该组频数加权；每条实测只贡献一次。补计数只改变 `N`，不改变实测的 `μ`、`q` 或 `s²`。

新试验默认 GB/T 16988-2013、分组、`h=2.5`、普通汇总。界面提供 1、1.5、2、2.5 μm 和原始直径选择；方法与组距是分别保存的设置，切换方法不会暗中重设当前组距。SN/T 0756、FZ/T 32004 和 FZ/T 30003 必须使用分组数据。

右侧类别表的均径始终是**原始实测均径**。计算摘要和 Excel 另列 `calculation_mean`／`calculation_stddev`，以免将界面原始均径误代入分组公式。原始样本只有一条时原始标准差为空；分组只有一条时计算方差为 0。原始单样本若选择需要方差的五个方法，则明确未就绪，不把缺失方差当作 0。

所有有效实测记录参与统计，分组数量动态扩展。原模板原始统计只有 1,500 行、分组频数只读取 1,488 行，并固定 201 桶；这些截断不继续保留，也不解释为原软件的用户测量上限。记录增删改和撤销／重做更新增量聚合；普通摘要开销随操作者和类别数变化，不随历史条数线性增加。

**设置重算与版本边界：**修改组距时，工作区只取得不可变记录引用的快照，在后台验证并重建聚合；改组距的撤销／重做走同一路径。重算完成前原设置、统计和实时画面继续有效；若期间记录或配置版本发生变化，结果丢弃并提示重试，不覆盖新账本。可取消重算；关闭时等待取消完成，未结束前保留窗口与任务。仅改方法／提醒或原样确认不会遍历历史。快照引用收集仍与条数成正比，完整数值计算不在 GUI 执行；大账本实际响应需专项验证。同步领域 API 为非 GUI 调用保留，工作区使用 deferred 接口。

模型与项目加载允许任意正有限组距；设置下拉框除四种常用值外，会保留已加载的“当前自定义”值。不分组时也保存原组距，不因确认其它设置而重置。上述配置修正晚于首轮正式性能快照，作为独立 overlay 记录；测试／重新冻结状态见 [配置修正身份](validation/cu-live-measurement-2026-10-15/configuration-rebuild-overlay.json)，不能用旧性能数据证明新增后台设置路径已验收。

## 2. 十一个方法的实际权重

先在当前操作者、当前方向计算每个有效类别的权重 `W_i`，一般归一化为 `C_i=100W_i/ΣW`。分母包括该方向所有有记录的类别；空类别不影响计算。FZ/T 30003 归一化后还执行第 4 节的经验修正。

| 方法标签 | 稳定方法 ID | 单类权重 `W` |
|---|---|---|
| GB/T 16988-2013 | `gb16988` | `(μ²+s²)Nρ` |
| ISO 17751-1:2016(E) | `iso17751` | `(μ²+s²)Nρ` |
| CNS 2339-1 L3050-1 | `cns2339` | `(μ²+s²)Nρ` |
| CAN CGSB-4.2 No.14-2005 | `can14` | `(μ²+s²)Nρ` |
| JIS L 1030-2：2012 | `jis1030` | `(μ²+s²)Nρ` |
| SN/T 1062-2002 | `sn1062` | `μ²Nρ` |
| FZ/T 01101-2008 | `fz01101` | `qNρ` |
| AATCC 20A-2018 | `aatcc20a` | `qNρ` |
| SN/T 0756-1999 | `sn0756` | 第 3 节修正后的平方量 × `Nρ`；苎麻按组上端选系数 |
| FZ/T 32004-2009 | `fz32004` | 第 3 节修正后的平方量 × `Nρ`；苎麻按组中值选系数 |
| FZ/T 30003-2009 | `fz30003` | 先以 `μ²Nρ` 归一化，再执行经验修正和首组分残差 |

因此前三种常见表达式不能互换：样本方差带 `m−1` 分母，`μ²+s²` 通常不等于 `q`，`μ²` 也不等于 `q`。代码以在线矩更新保存这些量；与按另一顺序求和的浮点结果允许出现最后若干位差异，不能用显示小数反推原始测量值。

## 3. SN/T 0756 与 FZ/T 32004 的棉麻分支

两种方法仅支持下表材料家族。材料名称可以编辑，计算分支由快照中稳定的 `family` 确定，不通过名称包含某个汉字猜测。

| 材料 | 内部家族 | 修正后的平方量 |
|---|---|---|
| 棉 | `cotton` | `0.2939q` |
| 亚麻 | `flax` | `0.42q` |
| 大麻 | `hemp` | `0.35q` |
| 罗布麻 | `apocynum` | `0.39q` |
| 苎麻 | `ramie` | `Σ(x_j²K(r_j))/m` |

苎麻系数为：

| 判断直径 `r`（μm） | `K(r)` |
|---|---:|
| `r < 15` | 0.3202 |
| `15 ≤ r < 40` | 0.2652 |
| `r ≥ 40` | 0.221 |

SN/T 0756 的 `r_j` 是该组**上端** `(k+1)h`；FZ/T 32004 的 `r_j` 是**组中值** `(k+0.5)h`。乘方的 `x_j` 在两者中仍然都是组中值。例如 `h=2.5`、组 `[12.5,15)`：两者平方项均为 `13.75²`，但 SN/T 0756 取 `K(15)=0.2652`，FZ/T 32004 取 `K(13.75)=0.3202`。`[37.5,40)` 同理跨越 40 μm 边界。不能先对全类均径选一个系数，也不能用模板旧缓存覆盖 VBA 的分支差异。

## 4. FZ/T 30003 的经验修正

此方法支持棉、苎麻、大麻、亚麻；不支持罗布麻或其它家族。它使用分组均径的平方 `μ²`，**不套用上一节的棉麻平方量系数或苎麻分段系数**。

1. 以 `W_i=μ_i²N_iρ_i` 求基础百分数 `p_i=100W_i/ΣW`。
2. 按已配置类别顺序取有记录的有效组分。存在多个有效组分时，首组分必须为棉，否则标记无效。
3. 首组分以后的苎麻保持 `p`；大麻改为 `1.3402p−0.0034p²`；亚麻改为 `1.3731p−0.0037p²`。其它受支持但无多项式的后续棉组分也保留基础值。每个后续值限制在 `[0,100]`。
4. 首组分取 `100−Σ后续修正值`。若残差小于 `−1e-10`，整个方向无效，不发布负的首组分含量；容差内的微小负值归零。

只有一个有效组分时结果为 100%，不触发“混纺首类必须为棉”的检查。多组分情况下类别顺序影响这条经验规则，不能只调整显示顺序而不提示用户重新核对。

## 5. 当前方向、经纬混合与多人汇总

这三个层级分别计算，右侧类别面板默认显示当前操作者的当前方向，和原 CU 面板层级一致。

| 层级 | 实际规则与分母 |
|---|---|
| 单人单方向 | 该方向权重归一化，保留未舍入百分数 |
| 单人经纬混合 | `C_i=(aC经_i+bC纬_i)/(a+b)`；`a,b` 为该操作者的经、纬重量 |
| 多人纤维汇总 | 引用每位操作者的**经向**结果，再按全部已建立操作者人数 `J` 平均 |
| 多人织物汇总 | 引用每位操作者的经纬混合结果，再按全部已建立操作者人数 `J` 平均 |

经纬重量必须非负且总和为正。某方向重量为 0 时不要求该方向先完成测量；重量大于 0 的方向必须就绪。同一材料在某个已就绪方向中缺席时，其含量贡献为 0。

跨方向、跨操作者按照**稳定材料 ID**匹配。CU 原模板按照类别名称匹配；本项目有意避免同名不同材料误合并，或改名后变成新材料。同一内置材料在不同人／方向中保持同一 ID 才会合并，名称相同本身不够。各人的密度与范围仍保存在各自试验快照中。

多人含量的分母是全部已建立并命名的操作者人数 `J`，不是“刚好测到该材料的人数”，也不是实测总根数。某个已经就绪的操作者未包含该材料时贡献 0；但某个操作者的整个所需结果尚未就绪时，**整个多人汇总未就绪**，不会跳过此人悄悄改变分母。不要为了占位而添加不参与测量的人。

多人纤维均径另按存在有效均径的操作者作算术平均，分母只计有该类均径的人，且不是按根数加权；织物混合层没有对应均径，因此不会伪造一个混合均径。纤维汇总固定引用经向，当前界面切到纬向不会改变这一报表定义。

## 6. 普通／免脱色汇总与舍入

普通 CU5／CU6 的模板相同；免脱色模板在 54 个最终汇总公式中增加一位小数处理，其余 14,349 个公式 token 相同。`profile=normal` 与 `profile=decolorization_free` 选择这两条**含量汇总**规则，不改变单方向权重，也不切换自动视场的缩小倍率。生产视场检测采用 CU6 的比较尺度及明确的强变化计数修正。

普通汇总先对每个多人平均含量使用恢复的 `RoundN(...,2)`。后续组分保留两位，首个有效组分最终取 `100−Σ后续已舍入组分`。首组分因此是残差，而不是独立舍入后的原始百分数。

`RoundN` 不是普通四舍五入：以绝对值计算，半位上下 `1e-10` 的容差以**未缩放的百分数值**计；落在容差带内按保留位整数奇偶取舍，最后恢复符号。原 VBA 严格比较在恰好容差边界处没有赋值，本实现将边界纳入奇偶分支，这是明确修复。带外按离半位的方向取整。

免脱色汇总先完成相同的两位小数处理，再将后续组分按一位小数的“五成双”规则舍入；首组分从这些最终一位值求残差后再取一位。实现以整数百分位判断 `.05` 的奇偶，避免显示上相同的半位因二进制表示差异走不同分支。例如三人汇总产生三个各 `100/3` 的组分时，普通显示 33.34、33.33、33.33，免脱色显示 33.4、33.3、33.3。

## 7. 未就绪与无效状态

| 条件 | 处理 |
|---|---|
| 空类别 `N=0` | 此行“尚无记录”，不阻塞其它有记录类别 |
| 整个方向无记录 | 方向未就绪 |
| 只有补计数，`m=0,c>0` | 未就绪；需要该类真实直径 |
| 密度缺失或为 0 | 未就绪；不得擅填通用密度 |
| 原始数据只有一条且使用五个方差法之一 | 未就绪；需要至少两条实测 |
| 单条分组直径 | 计算方差为 0；原始标准差仍为空 |
| 三个棉麻方法选“不分组” | 无效，要求分组 |
| 棉麻家族不支持、FZ/T 30003 混纺首类非棉 | 无效并给出对应原因 |
| 权重溢出、权重总和非正／非有限、经验修正首类显著为负 | 无效，不发布虚假的百分比 |
| 经纬总重量为 0，或所需方向未完成 | 经纬混合未就绪；不影响已经就绪的单方向结果 |
| 有参与者尚未完成所需结果 | 对应多人汇总未就绪；不悄悄跳过 |

材料目录恢复 40 条定义，普通版本共用前 37 条；免脱色新增的棕色棉、绿色棉、白棉原始密度为 0，仍保留 0，用户确认并填写正密度后才能得到含量。目录未恢复清楚的两个 double 字段没有赋予推测的业务含义。类别上下限负责测量确认，不是自动材料识别，也不替代密度。

## 8. 保存、导出与验证证据

项目保存完整试验、全部实测／补计数事件、操作者及材料稳定 ID、设置与材料快照，并可关联原图证据。撤销／重做不会用旧汇总值倒推记录。CSV 导出**原始测量与补计数账本**；Excel 除账本外，还包含当前同一统计引擎生成的方向统计、经纬／多人汇总、材料快照和适用的批次来源。Excel 是静态数值报告，不依赖 Excel COM，也不是原 CU `.xlt` 的公式逐格克隆；计数行的直径为空。实现见 [exports.py](../src/fdm/live_experiment/exports.py)。

独立 `Decimal` 数学 oracle 覆盖 **11 方法 × 4 组距 × 2 汇总版本 × 2 报表 = 176 配置**，每组包含三人、两方向和补计数，另测苎麻 15／40 边界、单样本、缺密度、空方向、零重量、多人分母及记录量边界。此矩阵是本项目的独立数学回归，不能称为 176 次原软件 Excel 实机对照。相关用例见 [test_live_experiment_content_statistics.py](../tests/test_live_experiment_content_statistics.py)。

恢复阶段另有原软件完整数据的 **24 个数值**对照：12 个单方向、6 个经纬混合、6 个汇总；20 个 double 按位相同，4 个差 1 ULP，最大绝对差约 `7.11e-15`。这一历史证据与当前 176 配置是不同的验证层级。
