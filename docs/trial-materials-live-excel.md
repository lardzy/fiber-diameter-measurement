# 试验类别、测量限值与 Excel 实时写入

适用于含量试验和直径试验。软件版本保持 **0.4.14**。

## 配置类别与试验目标

- 顶部 **试验 → 纤维类别库** 管理可复用定义。试验页工具菜单也有相同入口。表格显示密度、直径范围和状态，可搜索名称／别名、筛选内置／自定义／待完善类别；选中后在同窗口编辑。新增、复制、编辑和恢复先修改草稿，点击“保存类别库”才写入，取消丢弃草稿。已有试验的参数副本不随库修改。
- 试验页 **类别／选择本次纤维** 显示当前操作者和方向。在候选表直接勾选最多九类，右侧拖动或上／下移决定数字选类顺序；候选表搜索和排序不会改变该顺序。“本次参数”在同一区域编辑，不打开第二层窗口。点击“应用到本试验”一次提交；取消和无变化确认不创建撤销记录。
- 已有实测、补计或待确认测量引用的类别会显示不能移除的原因；仍可调整顺序和参数。类别重排会同步搬动 Excel 中的原始数据列、类别及密度，不只是更改列头。
- **常用组合**只保存类别 ID 和顺序，不保存密度和限值。加入组合时追加尚未选择的类别，保留已有顺序和本试验参数；缺失类别或超过九类时整次加入不生效。保存／重命名／删除组合是独立的应用偏好操作，取消本次试验配置不会撤销这些显式操作。
- 密度为零或缺失时标为“待确认密度”，原值保留；同义但 ID 不同的类别不自动合并。恢复当前内置项与恢复全部分开，后者位于更多菜单。
- 含量试验按所选类别的范围检查。建议类别尚未加入时，先加入，再处理原待确认结果；改类后仍越限需要再次明确确认。
- 直径试验的 **本场直径范围** 独立于类别范围。留空表示不限；填写 μm 正数，等于边界允许通过。可明确保存为以后新建直径试验的默认。
- 数量目标入口可设置单类覆盖和新试验默认。含量分别统计各类实测及本方向总数（实测＋补计），直径统计当前操作者的有效实测。达到目标提醒一次，仍可继续。
- **设置 → 采集与试验 → 测量与图片存档 → 数量提醒** 统一设置含量试验总根数，默认 1500。应用后作用于所有已有及以后新建的含量试验；重新打开旧项目也采用此值。按每位操作者的经／纬方向分别累计实测＋补计，不把不同方向合计。取消不修改，恢复本页默认回到 1500。总目标是应用偏好，不改变项目、撤销记录或 Excel 输入；试验内数量目标显示这个共享值并指向主设置。
- **纤维类别库**的详情中可以分别填写“实测直径提醒根数”和“补计／计数提醒根数”。两项使用正整数；实测留空继承试验默认（出厂 300），补计留空不提醒。补计只统计计数，不含已测直径。类别库用于以后选用；已有试验可在“选择本次纤维 → 本次参数”修改自己的副本。本试验明确设置的单类实测目标仍优先。直径试验继续采用当前操作者整体实测目标。
- 已入账记录的改径、改类也重新检查范围，并保留此次修订的范围和人工选择；撤销可还原。

## 实时 Excel

进入试验后自动建立工作簿，返回同一试验复用关联。对应的模板可在各自 **报告 → 选择模板** 设置；含量和直径的选择及映射分别保存。文件名不影响映射，工作表和单元格结构需要匹配。

**选择模板会实际更换当前试验的实时工作簿。** 从选定文件新建工作簿并写入完整试验数据，原工作簿留在 Excel 供用户保存；不会把原工作簿里的人工备注自动复制到新工作簿。即使选择同一路径，也重新加载该文件，适用于直接替换或编辑模板后重新选定。后续新试验使用新选择，其他已有试验保留各自的关联。更换输入映射或明确修改模板标准映射同样为当前试验建立新工作簿。

报告页分别显示“后续试验模板”和“当前实时工作簿模板”；排查时以第二项确认正在使用的来源。“重新输出测量数据”仍然只重建当前工作簿的量化输入，不更换模板。Excel 忙碌时等待当前批次完成后更换，失败时显示所选路径和原因，不回退到 CU 默认模板。

未主动选定模板时，首次把安装目录 `runtime/content-templates/sheet.xlt`（直径为 `sheet_dia.xlt`）复制到用户设置目录 `templates` 下。已有个人工作副本不会被安装目录更新覆盖，以保留用户修改的公式和宏。因此，**直接替换安装目录文件后，请在“报告 → 选择模板”明确选择替换后的文件**。选择后的路径优先于个人工作副本，文件名可任意。Windows 的用户设置目录通常是 `%LOCALAPPDATA%\FiberDiameterMeasurement`，报告页会显示实际路径。

底部 **查看 Excel** 主按钮打开关联工作簿；下拉菜单提供以下操作。状态栏或同步详情显示完整原因、容量提示、文件位置和最后确认时间。模板缺失或 Excel 不可用时仍能继续测量。

| 操作 | 作用 |
| --- | --- |
| 重新输出测量数据 | 重建量化输入；保留 Excel 中人工填写的样品、人员、设备、备注及标准／组距 |
| 更新报表信息… | 展示 FDM 当前信息，确认后写入所选内容；默认选择样品／人员信息，标准／组距需另行勾选 |
| 重新统计报表 | 按 Excel 当前标准和组距执行模板重算，不先恢复 FDM 设置 |
| 停止同步 | 不再写入；FDM 记录和已打开的 Excel 工作簿都保留 |

**持续同步的内容**是已确认的直径、分类、补计、类别名称、密度及经纬重量。新增只追加；改径更新对应位置；删除、改类及排序重建受影响列并清除旧尾部。未确认测量不写入，原图保存进度等无关变化不重写工作簿。原始值保留计算精度，显示位数由模板决定。

**只在首次创建时填写的内容**是样品编号／名称、日期、人员、标准和组距。之后用户可以直接在 Excel 修改；普通同步和重新输出测量数据均不覆盖。需要采用新的 FDM 信息时，使用“更新报表信息…”。设备、备注及模板其他内容始终由用户和模板管理。

FDM 不再添加工作表保护，也不会主动解除模板自身的保护。原始测量区由 FDM 维护，应在 FDM 修改这些测量；Excel 中对原始区的人工改动不会反向导入 FDM，后续受影响区域更新或重新输出可能覆盖它。

工作副本从模板创建，不覆盖模板原件。Excel 的保存、另存和宏操作由用户控制，FDM 不拦截保存、不自动保存。另存后继续关联同一工作簿。**“数据已写入”不等于报表计算完成或文件已保存。** 保存状态区分尚未另存、有未保存更改、已保存和暂时无法读取。

正常测量使用已有公式，不逐条重建分组。Excel 自动计算模式下公式正常更新；用户选择手动计算后，FDM 保持该选择并提示待计算，可在 Excel 或使用“重新统计报表”。原有一次性“导出”仍独立生成报告，使用该次导出时的 FDM 设置。

Excel 正在编辑、保存对话框或宏中忙碌时，FDM 继续记录并等待恢复。只读状态查询失败不触发测量数据重写；数据已经写入后的计算或状态查询失败也不撤销输入确认。真正的映射缺失、宏错误或连接中断在详情中显示阶段和调用栈，处理后可重试。手动关闭工作簿后停止同步，不因切页自动重开；显式重新输出时才创建新工作簿。

结束并换样或退出时先处理最终量化输入；未完成时可等待、重试或明确结束关联。不会要求先保存 Excel。旧工作簿继续留在 Excel 供用户使用。

## 模板统计范围与口径

已实际验证的原始模板与用户提供的 `sheet11.xlt`：

| 模板 | 已核对范围 | 超过范围时 |
|---|---|---|
| 含量 `sheet11.xlt` 与现有含量模板 | 原始统计 1500 条；分组 1488 条／类别输入列 | 完整写入，提示覆盖不足和可能少计数量 |
| 原直径模板 | 主统计 2976 条／操作员输入列 | 完整写入，提示主统计覆盖不足 |
| 直径模板内部分 TWC／ASTM 标准报告 | 部分公式只覆盖 1988 条 | 额外提示这些报告的覆盖限制 |

这些数量是已验证模板的公式边界，不是软件允许记录的根数上限。模板增改公式后，应重新核对映射和容量。

直径原模板 C9 使用**分组均值**；FDM 面板显示**原始均值**，数值可能不同。FDM 按自身试验设置计算，Excel 按当前模板设置计算。用户在 Excel 更改标准／组距后，两边口径可能不同，不据此报告同步失败。详细数值核对保留在验证工具中；容量提示不使用 FDM 当前标准推断人工调整后的 Excel 口径。

## 环境与边界

实时自动化需要 Windows 桌面 Microsoft Excel，通过系统 PowerShell STA 工作进程运行。没有新增 Python COM 包、Excel 插件或安装步骤；macOS 或未安装 Excel 的环境会显示不可用原因。

本轮源码及真实桌面 Excel 验证使用 Windows 11 虚拟机、隔离用户配置和测试工作簿。真实相机节奏、现场 Office 配置及实际业务报告仍需现场复核；未构建安装包，版本未增加。截图与录像继续留在本地。
