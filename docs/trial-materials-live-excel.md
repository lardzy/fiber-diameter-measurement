# 试验类别、测量限值与 Excel 实时写入

适用于含量试验和直径试验。软件版本保持 **0.4.14**。

## 配置类别与试验目标

- 顶部 **试验 → 纤维类别库** 管理可复用定义。试验页工具菜单也有相同入口。库中可添加、复制、编辑、删除和恢复内置定义，名称变更保留稳定 ID。密度、别名、直径范围、建议类别和参数来源一起保存。
- 试验页 **类别／选择本次纤维** 选择当前操作者、当前方向的最多九类，列表顺序对应数字选类。本试验保存独立参数副本，修改公共库不会追改已存在的试验。已有记录或待确认测量引用的类别须先处理引用后才能移除。
- 含量试验按所选类别的范围检查。建议类别尚未加入时，先加入，再处理原待确认结果；改类后仍越限需要再次明确确认。
- 直径试验的 **本场直径范围** 独立于类别范围。留空表示不限；填写 μm 正数，等于边界允许通过。可明确保存为以后新建直径试验的默认。
- 数量目标入口可设置单类覆盖和新试验默认。含量分别统计各类实测及本方向总数（实测＋补计），直径统计当前操作者的有效实测。达到目标提醒一次，仍可继续。
- 已入账记录的改径、改类也重新检查范围，并保留此次修订的范围和人工选择；撤销可还原。

## 实时 Excel

进入试验后自动建立工作簿，返回同一试验复用关联。对应的模板可在各自 **报告 → 选择模板** 设置；含量和直径的选择及映射分别保存。文件名不影响映射，工作表和单元格结构需要匹配。

底部 **Excel** 主按钮查看工作簿，下拉菜单提供 **重新同步、停止同步、同步详情**。紧凑状态栏区分同步状态与文件保存状态；悬停或打开详情查看完整原因、警告和文件位置。模板缺失或 Excel 不可用时仍能继续测量。

已确认的新增、改径、改类、删除、补计、撤销／重做及样品参数变化会同步。未确认测量不会写入。原始输入按完整数值写入，显示精度由模板决定。原图保存进度等无关变化不会重写工作簿。

FDM 管理原始输入区，并添加无密码保护；报告区保持可编辑。工作副本从模板创建，不覆盖模板原件。Excel 文件由用户在 Excel 中保存或另存，另存后的工作簿继续关联。**“已同步”不等于“文件已保存”。** 原有“导出”仍可另行生成一次性报告。

手动关闭工作簿后，本场停止同步；不会因切页自动重开。需要恢复时点“重新同步”，重建全部受管输入。Excel 忙于编辑或弹窗时，FDM 继续记录并合并最新状态；普通错误在页内显示，用户可处理后重新同步。

结束并换样或退出时先处理最终同步。未同步的真实关联会提供等待／重试或明确结束关联的选择。旧工作簿留在 Excel，供用户保存；解除关联撤回 FDM 添加的保护。停止同步不删除 FDM 试验记录，也不关闭用户工作簿。

## 模板统计范围与口径

已实际验证的原始模板与用户提供的 `sheet11.xlt`：

| 模板 | 已核对范围 | 超过范围时 |
|---|---|---|
| 含量 `sheet11.xlt` 与现有含量模板 | 原始统计 1500 条；分组 1488 条／类别输入列 | 完整写入，提示覆盖不足和可能少计数量 |
| 原直径模板 | 主统计 2976 条／操作员输入列 | 完整写入，提示主统计覆盖不足 |
| 直径模板内部分 TWC／ASTM 标准报告 | 部分公式只覆盖 1988 条 | 额外提示这些报告的覆盖限制 |

这些数量是已验证模板的公式边界，不是软件允许记录的根数上限。模板增改公式后，应重新核对映射和容量。

直径原模板 C9 使用**分组均值**；FDM 面板显示**原始均值**，数值可能不同。验证时分别检查写入原始值、原始区均值与模板分组结果，不把口径差异当作数据丢失。含量标准由本试验方法及其对应模板标签驱动，不沿用其他试验方法的全局标签覆盖。

## 环境与边界

实时自动化需要 Windows 桌面 Microsoft Excel，通过系统 PowerShell STA 工作进程运行。没有新增 Python COM 包、Excel 插件或安装步骤；macOS 或未安装 Excel 的环境会显示不可用原因。

本轮源码及真实桌面 Excel 验证使用 Windows 11 虚拟机、隔离用户配置和测试工作簿。真实相机节奏、现场 Office 配置及实际业务报告仍需现场复核；未构建安装包，版本未增加。截图与录像继续留在本地。
